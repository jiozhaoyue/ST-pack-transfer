# 10-30-production-readiness：正式上线前核心缺陷修复、交互定稿与发布治理

## Goal

彻底消除阻碍正式发布的 4 项关键缺陷与交互体验硬伤（图表展开跳顶、导出行错位、设置面板缺少默认项、发布部署机制），还原宿主品牌色联动，落地双通道首屏空态向导，并规范化发版部署与文案，使工具达到真正生产就绪标准。

## Requirements

### R1 图表树展开/折叠防跳顶与位置保持
- R1.1 用户在大类或子目录下展开/折叠文件夹时，**严禁图表视图跳至顶部**。
- R1.2 记录当前重绘前各个 `.chart-tree` 及其父容器的 `scrollTop` 状态，在重新渲染后精准回填。
- R1.3 展开操作不得触发无关节点的布局抖动或未经用户触发的自动滚动。

### R2 导出行排版重构（移至卡片头部）
- R2.1 彻底移除塞在图表分类树中间的 `.extension-tools` 导出行，消除结构突兀感。
- R2.2 将「扩展完整 / 扩展仅清单 / Git保留历史 / 保留构建配置」移至卡片头部，置于「导入01整包 2.0 GB」右侧/旁侧。
- R2.3 导出行样式与卡头紧凑对齐，支持在移动端和窄屏下自适应折行，不产生横向溢出。

### R3 设置面板新增导出默认项与持久化闭环
- R3.1 在设置面板（Settings Panel）中新增默认打包选项：
  - 扩展模式默认值（完整 / 仅清单）
  - Git 保留模式默认值（全部保留 / 仅更新所需 / 完全剔除，默认：仅更新所需，未勾选全部保留）
  - 保留构建配置默认值（默认：未勾选）
- R3.2 设置面板内的样式与卡头导出行保持一致（分段按钮 + 规范复选框），严禁出现未经样式修饰的原生大小不一的复选框。
- R3.3 将上述选项持久化至 `settings-store`（localStorage），初始化或导入新包时自动继承用户的默认偏好。

### R4 目标宿主品牌主题色联动
- R4.1 恢复此前深受好评的目标宿主品牌色联动设计：当用户切换目标宿主（ST / Luker / TT / PT）时，卡片内复选框（`accent-color`）、目标高亮徽标、选中态边框动态适配该宿主的品牌主题色（ST 红、Luker 纯黑/板岩灰、TT 金黄、PT 浅紫）。
- R4.2 严格遵守宿主主题继承规范，仅联动强调色（`--accent` / `--accent-soft`），不破坏酒馆原生深浅底色的继承。

### R5 双通道首屏空态向导与流量防护
- R5.1 当用户未导入任何数据包且未读取宿主时，图表区不得展示冰冷置灰的「宿主数据」不可用卡片。
- R5.2 呈现清晰的「双通道空态向导」：
  - 通道 A：【读取当前宿主】（标明按需请求，若开启流量提醒则提示拉取开销，必须由用户显式点击触发，绝不在后台自动偷跑流量/触发 408 超时）。
  - 通道 B：【导入已有数据包】（支持点击选择或拖放 .zip 文件）。
- R5.3 宿主数据读取成功后，平滑转入完整的图表树交互。

### R6 生产发布部署治理与 Commit 规范
- R6.1 将 `.github/workflows/deploy.yml` 触发器限定为：正式 Release 发布（`on: release: types: [published]`）与手动触发（`workflow_dispatch`），禁止普通 push 自动污染线上 Pages。
- R6.2 对外提交（git commit）严禁写任何本地绝对路径、用户个人信息或内部调试杂音，严格采用规范开源项目的 Semantic Commit 格式。

### R7 文案审查与定向测试
- R7.1 遵循 `scripts/copy-audit.js` 规范，对涉及改动的展示文案做精简优化（去除多余括号、消除分号长句、动宾一致）。
- R7.2 杜绝盲目全量慢速测试，只跑定向单元测试与自动化守卫（i18n、DOM 注入、Control Consumer）。

## Acceptance Criteria

- [x] AC-1: 在桌面和移动端展开/折叠图表树目录时，视图保持在当前滚动位置，无跳顶。
- [x] AC-2: 扩展导出行已移出图表树，在包卡头旁边正常显示且布局紧凑自适应。
- [x] AC-3: 设置面板包含扩展模式、Git模式、构建配置默认项，保存并能在重新加载时生效。
- [x] AC-4: 切换目标宿主后，图表区复选框及强调色联动呈现对应宿主品牌色（ST/Luker/TT/PT）。
- [x] AC-5: 零数据包状态下显示双通道引导卡，点击读取宿主提示流量并不自动静默请求。
- [x] AC-6: `deploy.yml` 仅响应正式 release 与手动触发；发版 commit 干净规范。
- [x] AC-7: 定向单测全绿，代码守卫通过（`check:i18n`, `check:dom-injection`, `check:control-consumer`, `check:copy`）。
