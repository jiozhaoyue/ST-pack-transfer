# UI 编排铁律（定型版）

> 2026-10-24 新建（任务 `10-24-ui-orchestration-impl` R-A3）。本文是工作台 UI 的**定型规范**：
> 收敛既有纪律（`workbench-single-view.md` §1/3/4/5 + `workbench-three-layer.md`）并补齐
> 按钮动词封闭集与帮助层铁律。每节「规则 + 判据 + 守卫」，凡可程序化断言的都已有守卫。
> 按主题独立成页：`component-guidelines.md` 已超注入上限，禁止追加。

---

## 1. 布局

| 规则 | 判据 | 守卫 |
| --- | --- | --- |
| 单一视图，无模式切换、无步骤条 | 模板不得出现 `data-wb-step` / `btn-wb-view-toggle` / `wizard-*` | `test/workbench-session.test.js` |
| 三层契约：模块纯渲染 / 流程清单 / 外壳摆法 | 模块层禁止判方向、写 media query、跨模块操作 DOM | 见 `workbench-three-layer.md` §1 |
| 无外层滚动条：根容器非滚动容器 | idle 态 `scrollHeight <= clientHeight + 1` 且 `overflow-y` 非 auto/scroll | `e2e/standalone/specs/s1-remedies.e2e.cjs` B2/B3 |
| 浮层必锚行：absolute 浮层的宿主行必须 relative | 展开菜单/帮助浮层与相邻区块矩形不相交 | 同上 E3；R2 详见三层页 §3 |
| 单行文字不折：按钮/徽标/标签 nowrap + flex-shrink:0 | 320px 视口控件单行高度 | 同上 D2/D3 |
| **禁做**：外层滚动条、浮层脱离锚行、文字竖排折行、模式切换控件 | — | — |

## 2. 控件

| 规则 | 判据 | 守卫 |
| --- | --- | --- |
| 多选一一律枚举（`select`），不用并排 radio | 三组枚举：`extension-mode-select` / `git-mode-select` / `restore-mode-select` | `check:control-consumer` |
| 控件必须有消费点：每个交互控件登记「谁读它的值」 | 声明表无僵尸、控件无漏登 | `npm run check:control-consumer` |
| 设置项单列不并排；折叠区紧凑成组 | — | 评审 |
| **按钮动词封闭集**：界面按钮文案只能取自下表；新增按钮**先扩表再写码** | 模板按钮 + 两列表模块生成的按钮 ⊆ 封闭集 | `test/ui-verb-table.test.js` |

**按钮动词封闭集**（2026-10-24 基线，扩表须改本页与该测试两处）：

```
丢弃 中止 取消 暂停 继续 全选 全不选 反选 载入 载入为源 下载 全部下载 批量转换
删除 移除 清空 存工作区 全部存入工作区 选位置导出 写回宿主
取消恢复 取消批量恢复 重试失败项 刷新页面生效
导入 导出 导出扩展清单 开始转换 继续转换 从宿主拉取 从聊天库导出
恢复到当前宿主 恢复到当前用户 确认恢复 发送到另一台设备
选择基准 ZIP 自动备份并预检目标 存储 引导 帮助 展开 收起 退出 确认拉取
```

> 单字符符号（`?` `×` `⋯`）是图标等价物，不受动词表约束。

## 3. 文案

| 规则 | 判据 | 守卫 |
| --- | --- | --- |
| 界面零说明性文案：无括号补充、无分号长句、无教学 tooltip、无空态解释段 | 渲染结果断言（读 `getWorkbenchHtml()`，不读源码） | `test/workbench-copy.test.js`（title ≤ 8 字等） |
| 禁黑话：「瘦身 / 剔除」等一律说人话 | 枚举/下拉文案 | 同上 |
| 状态读数可直接展示（如「按勾选透传」），但不得写成解释句 | — | 评审 |
| **禁做**：括号补充、分号、冒号长句、title 长文、空态解释段 | — | — |

## 4. 帮助与教程

| 规则 | 判据 | 守卫 |
| --- | --- | --- |
| 常驻说明为零；说明只活在引导动画与区块「?」浮层 | 界面文案守卫保持绿 | §3 守卫 |
| `HELP_TOPICS` 双向不悬空：主题 key ⇔ 模板 `data-wb-module` 一一对应 | 新增模块必须同步写帮助 | `test/help-topics.test.js` |
| 帮助文案同受文案铁律：标题 ≤ 8 字、要点 ≤ 5 行 × ≤ 16 字、无括号/分号/冒号 | 同上 | 同上 |
| 引导可重放、可退出、高亮真实控件 | — | `e2e`（workbench-shell A2） |

## 扩表/改规流程

1. 动词表与各守卫的期望值改动**先落本页**（本页是唯一权威表述）；
2. 同步改对应测试/守卫，两处不一致以本页为准修测试；
3. 禁止「先写码后补表」——守卫红灯时先问「该扩表还是该换词」，扩表是产品决策，不是绕过手段。
