# 项目铁律（会话 / 每条用户消息自动注入）

> 本文件是**唯一注入源**。改这里 = 改所有会话的强制提醒；**不要改 hook 脚本来改规则**。
> hook 只负责读取 `## 铁律` 与 `## 每轮收口` 两节。保持短、可执行；细节仍以 `CLAUDE.md` 与 `.trellis/spec/` 为准。

## 铁律

1. **文档先行，禁止直接读源码理解功能**：先查 `docs/DEVELOPER-GUIDE.md`、`.trellis/spec/`、`mini-trellis mem recall`。文档不足时**先补文档**，做到「只读文档就能知道怎么改」。只有进入编辑阶段，才允许读目标源码片段；读完把知识回流到文档。
2. **计划先行**：任何多项改动先落当前计划文件（`docs/PLAN-*.md` 或对应任务 PRD），写清目标、判据、改点、依赖、分工；实时更新状态，不凭记忆。
3. **检索先行**：实现前先查现成方案（WebSearch/WebFetch + GitHub API）。不造轮子。
4. **变更可审**：比较用 diff；改文件用块级 `Edit`，禁止整文件 `Write` 覆盖；禁止 shell 重定向改源码。
5. **数据正确性优先**：读数/体积/勾选必须同源、实时、可复核。读不到就如实显示「未提供」，禁止假 0、假缓存、假成功。
6. **布局铁律**：控件与自身文字不得拆行；图表用自适应网格（宽屏最多 4 列），**不得压成单条并排**；每个图表 DOM 边相互贴着、可拖拽改高宽、不留空白；默认隐藏容器必须补高特异度 `[hidden]` 规则。
7. **CSS 作用域**：所有规则必须挂在 `#app.app-container`（独立态与模态态统一根）或自有覆盖层 id（`#st-converter-modal-overlay` / `#wb-detail-overlay`）之下；`.st-converter-drawer-app` 随抽屉注入已于 2026-10-15 删除，出现即陈旧。颜色只用 `var(--SmartTheme*, 回退值)`。
8. **单一模板源**：业务节点只写在 `src/ui/workbench-template.js`；新增控件必须同步 `REQUIRED_TEMPLATE_IDS` 与 `CONTROL_CONSUMERS`。
9. **宿主差异只进 `host-bridge.js`**；平台码/布局码经 `hostLayoutCode()` 归一；禁止同构假设，先读宿主 `docs/**`。
10. **异步安全**：Worker `terminate()` 后置空引用；任何 `await` 必须有界可 settle；高频进度回调 rAF 合帧。
11. **高风险先问**：删除/覆盖文件、安装包、大重构、对外可见写操作（PR/评论/推送）必须先获用户授权。
12. **命令纪律**：单命令 ≤ 10 秒；长任务后台化；互相独立的命令并行发；禁止 `sleep`/轮询等待。
13. **测试即门槛**：`npm test` 全绿 + 五个 UI 守卫；E2E 只连 Dev 实例；完成即推送 `origin`（用户未说「先不要推」时）。
14. **中文**：文档、注释、回复一律中文（代码标识符、命令输出、专有名词除外）。
15. **禁止 AI 自测 / 自拟提示词互喂**：不测试 skill、不生成提示词喂给子代理做对照实验；只做用户点名的线。
16. **只认上游宿主**：Luker 只认原上游；任何 fork 仅作开发版，不得把 fork 特有行为当产品事实。
17. **宿主设置只读**：从宿主拉取只打开原生拉取位置，弹窗提示用户自己点「从宿主拉取」；禁止自动点注入按钮，禁止更改宿主任何勾选或设置记忆。默认不勾选仅在拉取后的插件侧生效。
18. **注入源唯一**：规则只改本文件；hook 必须读文件，不得把规则硬编码进 hook。
19. **注入频率**：会话启动强制注入一次；之后 UserPromptSubmit **每 5 条用户消息注入一次**，不逐条刷屏。
20. **检索门禁**：本会话未完成 Web/GitHub 检索前，search-gate 拦截实现类写操作；规划目录 `.trellis/`、`docs/`、`tasks/` 与只读操作放行；紧急禁用 `TRELLIS_SEARCH_GATE=0`。
21. **本地专属目录永不入库**（2026-11-05 用户明令）：`test/` `e2e/` `scripts/` `fixtures/` **绝对不纳入版本控制**、**绝不上传到任何云端仓库**（含 S3 包仓库）；禁止 `git add -f` 强制加入。判据：`git ls-files test e2e scripts fixtures` 恒为空。
