# 项目铁律（会话 / 每条用户消息自动注入）

> 本文件是**唯一注入源**。改这里 = 改所有会话的强制提醒；**不要改 hook 脚本来改规则**。
> hook 只负责读取 `## 铁律` 与 `## 每轮收口` 两节。保持短、可执行；细节仍以 `CLAUDE.md` 与 `.trellis/spec/` 为准。
>
> 配套（不注入，按需读）：
> - `rule-catalog.md` —— R-01~R-30 判据与校验映射
> - `rule-details.md` —— 技术细则（每条挂规则 + 原文证据）
> - `rule-triggers.md` —— 触发词索引（提到什么就读哪份规范）
> - `scroll-containers.md` —— 滚动容器与拖拽分隔条契约
> - `details/` —— 分源补充细则（zcode / agy / OpenCode / 滚动专项）

## 铁律

1. **文档先行，禁止直接读源码理解功能**：先查 `docs/DEVELOPER-GUIDE.md`、`.trellis/spec/`、`mini-trellis mem recall`。文档不足时**先补文档**，做到「只读文档就能知道怎么改」。只有进入编辑阶段，才允许读目标源码片段；读完把知识回流到文档。
2. **计划先行**：任何多项改动先落当前计划文件（`docs/PLAN-*.md` 或对应任务 PRD），写清目标、判据、改点、依赖、分工；实时更新状态，不凭记忆。
3. **检索先行**：实现前先查现成方案（WebSearch/WebFetch + GitHub API）。不造轮子。
4. **变更可审**：比较用 diff；改文件用块级 `Edit`，禁止整文件 `Write` 覆盖；禁止 shell 重定向改源码。
5. **数据正确性优先**：读数/体积/勾选必须同源、实时、可复核。读不到就如实显示「未提供」，禁止假 0、假缓存、假成功。
6. **布局铁律**：控件与自身文字不得拆行；图表用**动态自适应网格**（1 个占满、2 个平分、3 个四宫格留空一格，宽屏最多 4 列），**不得压成单条并排**；**禁止自由拖拽卡片尺寸**——拖拽只允许调整既有分隔条比例（见铁律 26），不得任意改单卡宽高；每个图表 DOM 边相互贴着、不留空白；默认隐藏容器必须补高特异度 `[hidden]` 规则。
7. **CSS 作用域**：所有规则必须挂在 `#app.app-container`（独立态与模态态统一根）或自有覆盖层 id（`#st-converter-modal-overlay` / `#wb-detail-overlay`）之下；`.st-converter-drawer-app` 随抽屉注入已于 <DATE> 删除，出现即陈旧。颜色只用 `var(--SmartTheme*, 回退值)`。
8. **单一模板源**：业务节点只写在 `src/ui/workbench-template.js`；新增控件必须同步 `REQUIRED_TEMPLATE_IDS` 与 `CONTROL_CONSUMERS`。
9. **宿主差异只进 `host-bridge.js`**；平台码/布局码经 `hostLayoutCode()` 归一；禁止同构假设，先读宿主 `docs/**`。
10. **异步安全**：Worker `terminate()` 后置空引用；任何 `await` 必须有界可 settle；高频进度回调 rAF 合帧。
11. **高风险先问**：删除/覆盖文件、安装包、大重构、对外可见写操作（PR/评论/推送）必须先获用户授权。
12. **命令纪律**：单命令 ≤ 10 秒；长任务后台化；互相独立的命令并行发；禁止 `sleep`/轮询等待。
13. **测试即门槛**：`npm test` 全绿 + 五个 UI 守卫；E2E 只连 Dev 实例；完成即推送 `origin`（用户未说「先不要推」时）。
14. **中文**：文档、注释、回复一律中文（代码标识符、命令输出、专有名词除外）。
15. **禁止 AI 自测 / 自拟提示词互喂**：不测试 skill、不生成提示词喂给子代理做对照实验；只做用户点名的线。
16. **只认上游宿主**：Luker 只认原上游；任何 fork 仅作开发版，不得把 fork 特有行为当产品事实。
17. **宿主设置只读**：从宿主拉取只打开原生拉取位置，弹窗提示用户自己点「从宿主拉取」；禁止自动点注入按钮，禁止更改宿主任何勾选或设置记忆。默认不勾选仅在拉取后的插件侧生效。
18. **注入源唯一**：规则只改本文件；hook 必须读文件，不得把规则硬编码进 hook。
19. **注入频率**：会话启动强制注入一次；之后 UserPromptSubmit **每 5 条用户消息注入一次**，不逐条刷屏。
20. **检索门禁**：本会话未完成 Web/GitHub 检索前，search-gate 拦截实现类写操作；规划目录 `.trellis/`、`docs/`、`tasks/` 与只读操作放行；紧急禁用 `TRELLIS_SEARCH_GATE=0`。
21. **版本控制白名单以 `.gitignore` 为唯一事实源**（<DATE> 修正）：`test/` 已按 <DATE> 后续裁定纳入版本控制（实测 143 个文件在库）；`scripts/`、`e2e/`、`fixtures/` 仍被忽略。任何「某目录是否入库」的表述必须由 `git check-ignore` / `git ls-files` 实测得出，**禁止凭记忆断言**；文档与 `.gitignore` 矛盾时以实测定性并立即改正文档。
22. **文档与 README 同步**（<DATE> 用户明令）：每次功能更新 / 行为变更，必须在**同一次提交内**同步更新 `docs/DEVELOPER-GUIDE.md` 与 `README.md`；判据：`git diff` 中改动的 `src/` 文件必须在两份文档里有对应条目或读法更新，只改代码不改文档视为未完成。
23. **实例实测一律 Playwright 无头 · 后台**（<DATE> 用户明令）：Dev 实例（尤其 Dev Luker）的界面实测必须用 **Playwright 无头浏览器**完成，走 `e2e/` 的库 API（`lib/resolve-playwright` 解析本机全局，**不新装包**），**后台运行**、不得弹出前台窗口、不占用前台浏览器面板；读数与截图落盘后再汇报。
24. **响应式美学铁律**：任何响应式都**不得**产生不美观的响应；美观优先，**不为塞下而硬做，也不能显示不全**。允许的退让只有「换行 / 堆叠 / 容器滚动 → 整块隐藏次要信息 → 纯图标（带 aria-label/title）」；**禁止**压扁控件、缩小字号硬塞、`line-clamp` 裁掉功能性文案、固定高度内裁切。判据见 `.trellis/spec/frontend/responsive-and-aesthetics.md`。
25. **滚动容器唯一 · 可判定**：每个视图（独立态 / 插件态 / 手机态）**只允许一个纵向滚动容器**；`overflow-x` 一律 `hidden`，**禁止横向滚动条**；内容未溢出时不得出现常驻滚动条（`overflow: scroll` 禁用，只用 `auto` / `visible`）；滚动条宽度必须落在统一细条名单（`scrollbar-width: thin` 或 6px 自定义），不得落系统粗条；手机全高用 `100dvh` 且保留 `100vh` 兜底，保证底部可达。判据见 `.trellis/spec/guides/scroll-containers.md`。
26. **拖拽分隔条白名单**：分隔条**只允许**存在于 ①图表之间 ②存储图表与数据包列表之间；每个分隔条必须有在 `style.css` 登记的唯一类名；**手机端一律禁用拖拽手柄**（布局保留、交互关闭）；新增分隔条类名必须同步模板源与 `CONTROL_CONSUMERS`。判据同上。
27. **性能预算**：交互反馈 ≤ 100ms；本地部署从宿主拉取 ≤ 10s；任何操作**不得慢于宿主原生**（曾实测慢 20 倍）；插件首屏与教程浮层必须即时，不得"操作几次后才出现"。
28. **宿主原生优先**：动手前先盘点宿主**原生已提供**的能力（拉取 / 上传 / 下载 / 扩展管理 / 存储页 / 通知）；原生已实现的不在插件内重造；通知一律走宿主原生通道；与原生并发时**宿主优先，插件不抢占**。
29. **全平台一致**：web / 手机 / 竖屏三种形态下功能按钮**必须全部显示、不得压缩**；配额与占用在所有平台都能读到且**同源**；读数 UI 与交互逻辑跨平台一致；标签只用一种语言。
30. **失败不静默**：任何耗时操作必须有可见进度与明确结果，**不得只剩空面板或暗遮罩**；失败不得让整体中断——必须保存进度、输出完整报告，并让用户选择丢弃或保留部分成果；提示必须可持久化（默认每次提醒）；宿主不支持的能力如实说明，**禁止返回假空清单**。
31. **交付落点唯一**：规则与规范**只写 `.trellis/spec/`**；仓库根目录**不得新增规则 md**；被 `.gitignore` 忽略的目录（`scripts/`、`.private/`、`e2e/`、`fixtures/`）里放的东西**不算交付**。判据：`git check-ignore` 对规范文件无输出。
32. **安装来源唯一**：同一作者/仓库**只允许一个安装 URL**；支持 `/tree/<branch>` 与指定 commit；私有仓须在安装前或失败时提示"含私有，需登录"；一律 **remote link**，禁止本地链接。
33. **实例边界三类**：宿主实例内，运行时数据**可读写**；被 git 跟踪的宿主源码**严禁改动**；指向工作区仓的 junction / symlink **严禁写穿**。实例更新只走 git 或宿主原生安装器。
34. **禁止硬编码**：尺寸、超时、上限、分块大小、URL、端口、平台名、颜色、文案一律走常量 / 配置 / i18n。`src/**` 不得出现裸 `#rrggbb`（`var(--SmartTheme*, 回退)` 除外）、不得硬编码端点与端口；平台判断只走 `hostLayoutCode()` 等归一入口。
35. **禁止本地绝对路径**：任何入库文件不得出现 `C:\`、`/c/Users/`、`/d/Repo`、`%APPDATA%` 展开路径。一律用 `<PATH>` / `<HOME>` 占位或相对路径。判据：`git grep -nE '[A-Za-z]:\\\\|/c/Users/|/d/Repo'` 为空。
36. **规则正文不带日期**：本文件、细则、触发索引中**不得出现任何日期**；历史日期只保留在 spec 变更记录与 journal。判据：`git grep -nE '20[0-9]{2}-[0-9]{2}-[0-9]{2}'` 对本文件为空。
37. **出声（过程可见）**：使用任何工具时，**同一轮回复内必须有可读文本**——正在做什么、看到什么、下一步，禁止只发工具调用。写规则 / harness / 配置前先报备**绝对路径 + 改动内容 + 原因**；写完立刻汇报实际结果并**读回校验**（grep 到标记）。宁可不动手，也不静默动手。
38. **持久服务用系统 shell**：dev server 等长驻服务必须用系统命令启动为独立进程（Windows `Start-Process` / POSIX `nohup`、`setsid`），禁止用 agent 内置后台 shell——其受 timeout 约束会被 SIGTERM 终止；判据见 `rule-details.md` D-93。
