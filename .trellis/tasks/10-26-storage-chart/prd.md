# 单一存储图表与逐文件选择

## Goal

面板只有一个存储图表；树精确到文件；配色继承酒馆主题、品牌色只做标识；分卷后按卷生成多张标准图表卡；多选包时并列多组图表。父任务 R2 / R9 / R12。

## Requirements

### 图表本体

- R2.1 面板只有一个图表容器；无包时显示宿主，选中包即切到该包；切包只换数据，不重扫、不重建容器。
- R2.2 布局：配额表头（浏览器 + 宿主两处）+ 树主体。宿主无读数时置灰并写明原因。
- R2.3 分类用插件自建类型表；**不得出现「其他」**；无法识别时给显式「未识别」节点（路径 + 大小 + 默认不勾）。
- R2.4 逐级复选框，大类默认折叠、可展开到文件；父级三态；每张图表卡带全选/全不选/反选。
- R2.5 建议色 + 图例 + 悬浮说明；默认不勾的项也要有颜色语义。
- R2.6 差量（覆盖 / 增量）作为图表顶部切换，不设独立差量区。
- R2.7 扩展为一级节点，含「完整扩展 / 仅列表」、Git 保留项、构建配置，全部**正向复选框：勾了才保留**。
- R2.8 勾选状态按「宿主 + 包」记忆，换包不串；多包多卷互不影响。

### 逐文件（R12.1–R12.3）

- R12.1 目录节点必须可展开到具体文件；不得只给一个大类而没有可选文件。
- R12.2 树结构按真实备份包取证（父 PRD 附录 A）：`chats/<角色>/<聊天>.jsonl`、`characters/*.png`、`worlds/*.json`、`user/images/<合集>/`、`user/files/<插件数据>`、`extensions/<扩展>/`、`themes|context|instruct|sysprompt|reasoning|QuickReplies/`、`settings.json`、`secrets.json`、`backups/*.jsonl`。
- R12.3 「私有配置」为一级节点并逐文件列出各宿主私有件（Luker `*.luker-state.*.json`、`secrets.json` 等）；同一文件不得在两个节点下重复计数。

### 分卷与多图表（R12.4–R12.8）

- R12.4 分卷单位只有 MB，单卷限 **32–2048 MB**，输入框旁显示 `MB`；越界即时提示、失焦钳制。
- R12.5 分卷后**每卷一张标准图表卡**：卡头显示卷号与本卷容量，组头显示包序号与整包容量。
- R12.6 装卷必须能**下钻到子项**（一级分类常大于单卷上限）；单文件本身超上限时该卷标「超单卷上限」并提示，不得静默放行。
- R12.7 0 字节节点不得单独成卷。
- R12.8 多选包时按包分组并列多组图表；桌面网格、移动端单列折叠（默认只展开第一卷）。

### 配色（R9）

- R9.1 面板底色、文字、边框、强调色**一律继承 `--SmartTheme*`**，插件不自建色板。
- R9.2 轮廓必须由 BodyColor 派生（宿主默认 `BorderColor` 是 `rgba(0,0,0,.5)`，深色底不可见）。
- R9.3/R9.4 四平台品牌色按官方图标取色（ST `#a11b1b`、Luker 纯黑剪影、TT 浅黄、PT 紫），**只用于标识**，禁止染按钮/勾选/进度条。
- R9.5 Luker 图标为纯黑，深色底必须垫浅底。

## 约束

- `src/core/` 禁止 DOM；图表渲染不得直接读宿主全局，一律经适配器与注入接缝。
- 大包数千文件：默认折叠 + 超阈值虚拟滚动 + 进度回调必须 rAF 合帧。

## Acceptance Criteria

- [ ] AC-6 面板只有一个图表容器；宿主/包切换只换数据不换容器；宿主无读数时置灰并给原因。
- [ ] AC-7 图表分类无「其他」；未识别项显式；私有配置为一级节点且逐文件；同一文件不重复计数。
- [ ] AC-8 勾选可作为导出选择器；勾选按「宿主 + 包」记忆。
- [ ] AC-9 分卷输入限 32–2048 MB 并显示 MB；填值后图表变多张标准卡；每张显示本卷与整包容量；超上限有显式标记；无 0 MB 空卷。
- [ ] AC-10 四种酒馆主题下（含深色）面板轮廓清晰；品牌色只出现在标识元素上；Luker 图标可辨。
- [ ] AC-11 移动端多卷单列折叠且默认只展开第一卷。
- [ ] AC-12 专用单测覆盖：三态、记忆键、分卷分配（含下钻与超限）、多卷/多包渲染。
