# 存储图表工作台总任务

## Goal

四酒馆数据包工作站以单一存储图表为核心的 UI 重构总任务：图表化一切、导入导出分区、数据包区、教程、命名与注入、私有格式存储

## Requirements

### R1 命名与入口

- R1.1 仓库与插件改名 `ST-pack-transfer`，中文显示名「数据包转运」；所有引用同步（manifest、package.json、文档、E2E、注入文案、`data-name` 匹配）。
- R1.2 目标平台选择器只有四项，文案为四酒馆**英文全称**（SillyTavern / Luker / TauriTavern / PureTavern）；当前宿主在对应项后加徽标；删除 `native` 选项与 `hostLayoutCode('native')` 分支。
- R1.3 打开入口：用户设置扩展列表做**与其他扩展一致的内联下拉**，下拉内容只有「打开面板」；账号弹层/管理面板原生备份按钮旁保留入口；Luker 备份管理器行保留。**扩展菜单（顶栏魔方棒）绝对不注入**。
- R1.4 四宿主入口一致，宿主重渲染后自动自愈。

### R2 存储图表

- R2.1 面板**只有一个图表**；无包时显示宿主；选包即切到该包；切包不重扫。
- R2.2 布局：**配额表头 + 树主体**。表头含两处配额（浏览器、宿主）；宿主无读数时置灰并说明原因。
- R2.3 分类使用**插件自建类型表**，覆盖四宿主全量类目；含宿主派生缓存、私有配置、原生资产、各包类型、扩展、Git 保留项、构建配置、差量。私有配置作为**图表一级节点**；未识别项显式标注，不伪装成其他类目。
- R2.4 逐级复选框，大类默认折叠、可展开到文件；父级三态；提供全选/全不选/反选。
- R2.5 用颜色 + 图例 + 悬浮说明标出「建议选 / 不建议选」，即使默认不勾也要有颜色语义。
- R2.6 差量（覆盖 / 增量）作为**图表顶部切换**，不设独立差量区。
- R2.7 扩展作为一级节点，展开含「完整扩展 / 仅列表」、Git 保留项、构建配置；全部为**正向复选框：勾了才保留**。
- R2.8 勾选状态按**宿主 + 包**分别记忆；换包不串。
- R2.9 能力矩阵：Luker 走原生 `storage/inspect` 钻到文件；PT 同源 Dexie 枚举；TT 走 `window.__TAURI__.fs` 枚举本地数据目录；ST 无清单端点，宿主图表置灰。
- R2.10 图表勾选即**导出选择器**，勾什么导出什么。

### R3 分区与流转

- R3.1 只有**导入区**与**导出区**，单向流转。
- R3.2 导入区收纳：宿主拉取产物、用户上传包、未识别 ZIP。
- R3.3 导出区收纳：点「生成导出包」后产生的**只读副本**；可「复制回导入区」再编辑。
- R3.4 导入区到导出区为**复制后解耦**，删除任一侧不影响另一侧。
- R3.5 按钮命名为「生成导出包」。
- R3.6 两区都可直接删包，删除需确认。
- R3.7 多选后的可用操作**按所在区限定**：导入区只能生成导出包/合并上传；导出区只能下载/回传宿主。
- R3.8 多选合并上传遇到同名路径**即停并提示**，要求用户先本地编辑或改名。
- R3.9 导出后默认在导出区保留包；可选「导出后删除」并二次确认 + 不再显示；设置里可重新开启。
- R3.10 向后端（ST/Luker）上下传默认提示耗费流量；可不再显示；设置里可开关。

### R4 数据包区

- R4.1 只有一个数据包区，选择区下方为包卡列表。
- R4.2 包卡术语统一为「包卡」；显示名称 + 格式宿主 icon + 大小 + 导入时间。全名查看：桌面悬停、手机点击。
- R4.3 默认按导入时间倒序；提供名称、大小、导入时间等全量排序。
- R4.4 四宿主 icon 作为本地资源内置；格式通过**注册表**插拔扩展，后续新增宿主不改主流程。

### R5 私有配置与容器

- R5.1 取消现有「仓」概念与独立区块。
- R5.2 私有配置随包同行；导出容器为插件自有、zip 兼容格式，内含 manifest 标明每个成员的来源格式与类型，并原样保存私有文件。
- R5.3 兼容性是**动态**的：目标宿主匹配时，用该宿主**原生导入**完整还原其私有配置，不存在例外；不匹配时原样存储，类型仍明确。
- R5.4 ST/Luker 私有配置「传云」走原生 `/api/files/upload` 存入 `user/files/`；可列、可下载、可删除、可校验；上传前有清单预览与流量提示。
- R5.5 图表不得出现「其他」；实在无法识别时显示**显式未识别**节点（路径 + 大小 + 默认不勾）。
- R5.6 非酒馆 ZIP **允许**导入，包卡标「未识别包」，图表逐文件列出，不提供转换，只能存储/导出/删除。

### R6 教程、文案与占位符

- R6.1 基础教程 **7 步**：宿主拉取 → 看图表 → 精简勾选 → 选目标平台 → 不分卷 → 生成导出包 → 导出完成。首次自动弹一次，可跳过，可重放。
- R6.2 进阶教程：上传 → 逐项引导选择 → 选目标平台 → 导出 → 结束。
- R6.3 日志只记事实；日志旁禁止说明文字（如「宿主类型服务端校验一致…」）。
- R6.4 问号键全部修好：修裁切、锚定、随模块重建，不留死键。
- R6.5 占位符完整集合：`host/target/user/part/date/time/datetime/mode/category/source/count`；各占位符语义独立；`{target}` 输出四酒馆英文全称；`{datetime}` 到秒。默认模板 `{target}_{user}_{part}_{datetime}.zip`。
- R6.6 文案纪律：无括号说明、无分号长句、无教学口吻；说明只活在问号浮层与教程。

### R7 分卷

- R7.1 单位仅 MB；填入数值即模拟分卷结果。
- R7.2 分卷只能在整包落到浏览器暂存之后进行；四宿主一致，宿主直拉分卷不可行。
- R7.3 每个分卷都是**独立可导入**的合法包。

### R8 Demo

- R8.1 单文件离线 HTML，双击即开；桌面与移动双形态；含模拟数据与全部关键交互。
- R8.2 必须展示：配额表头 + 树主体、四宿主可读/不可读、私有配置、未识别包、分卷、导入/导出区、包卡、日志、教程、问号浮层。
- R8.3 Demo 只是中间评审件；最终交付物是插件本体。

## 补充需求（2026-10-27 UI 评审轮）

> 本节覆盖/细化前面的 R2 / R4 / R7，并新增 R9–R12。冲突时以本节为准。

### R9 品牌色与主题继承

- R9.1 面板底色、文字、边框、强调色**一律继承酒馆主题令牌**（`--SmartThemeBlurTintColor` / `ChatTintColor` / `BodyColor` / `QuoteColor` / `UnderlineColor` / `EmColor`），插件不自建独立配色。
- R9.2 真机默认 `--SmartThemeBorderColor: rgba(0,0,0,.5)`，深色底上不可见。**面板轮廓必须由 BodyColor 派生**（`--outline`），保证任何主题下都有明显轮廓；不得直接用宿主边框色当轮廓。
- R9.3 四个平台品牌色**从官方图标取色**（取证见 §附录 A）：
  - SillyTavern `#a11b1b`（`public/img/logo.svg`）
  - Luker **纯黑剪影**（`public/img/apple-icon-512x512.png`）
  - TauriTavern 浅黄 `#f8c034`（词标 Tavern 段）
  - PureTavern 紫 `#584078`（词标）
- R9.4 品牌色**只用于标识**：包卡图标环、宿主角标、来源标签、目标平台下拉图标。**禁止**用于按钮、勾选框、进度条、焦点框等面板强调色。
- R9.5 Luker 图标为纯黑，深色底上必须垫浅底，否则不可见。

### R10 顶栏、日志与文案

- R10.1 顶栏徽标：插件模式 = 宿主 icon + 宿主英文全名 + 「插件」；Web 模式 = GitHub 图标 + 「Web」。
- R10.2 日志**从右栏移除**，改为顶栏按钮打开弹窗；按钮在出现 WARN/ERROR 时显示红点。
- R10.3 面板内**禁止写说明性文字**（如「导出区只读 · 可复制回导入区」），说明只进「?」浮层与教程。
- R10.4 同一信息不得在多处重复出现（例：宿主名不得在顶栏与图表各写一遍）。

### R11 布局与分隔

- R11.1 桌面左右栏可拖拽（分隔条 8px，悬停显线）；右栏内「数据包 / 执行」可上下拖拽。
- R11.2 两条分隔条的**交叉点**为十字光标手柄，一次拖动同时改宽与高，位置必须正压在交点上。
- R11.3 「执行」面板贴底，各面板不留外空白；间距收窄（8px 级）。
- R11.4 包名输入框占满整行宽度，并可纵向拖拽调整高度。
- R11.5 数据包区：选择数据包、格式、排序**固定不动**，只有包卡列表滚动。
- R11.6 移动端：分隔条全部隐藏；多卷图表竖向折叠，默认只展开第一卷；不得出现吸底条覆盖列表。

### R12 图表树与分卷（修订 R2 / R7）

- R12.1 图表树**必须精确到文件**；目录节点必须可展开，不得只剩一个大类而无可选文件。
- R12.2 树结构按**真实备份包**取证（§附录 A）：`chats/<角色>/<聊天>.jsonl`、`characters/*.png`、`worlds/*.json`、`user/images/<合集>/`、`user/files/<插件数据>`、`extensions/<扩展>/`、`themes|context|instruct|sysprompt|reasoning|QuickReplies/`、`settings.json`、`secrets.json`、`backups/*.jsonl`。
- R12.3 「私有配置」为一级节点并**逐文件列出**各宿主私有件（Luker `*.luker-state.*.json`、`secrets.json` 等），同一文件不得在两个节点下重复计数。
- R12.4 分卷单卷容量限 **32–2048 MB**，输入框旁显示 `MB`；越界即时提示，失焦时钳制。
- R12.5 分卷后**每卷一张标准图表卡**：卡头显示卷号与本卷容量，组头显示包序号与整包容量。
- R12.6 分卷要能**下钻到子项**再装卷；单文件本身超上限时该卷标「超单卷上限」并提示，不得静默放行。
- R12.7 0 字节节点不得单独成卷。
- R12.8 多选包时按包分组显示多组图表；批量全选/反选作用于全部选中包；勾选状态按包隔离。

### R4 修订：包卡

- R4.2a 包卡序号：两区**各自**按导入时间编号；列表只显示两位数字（如 `05`），压在图标左上角，不占包名宽度；图表组头显示 `导入05` / `导出01`，不再带「包·」前缀。
- R4.2b **删除**包卡的「在图表中查看」按钮——点卡即切换图表，作用重复的控件一律不留。
- R4.2c 包名允许折成两行，但仅当折行后尾行宽度 ≥ 整行 45% 时才折；否则单行省略（禁止出现第二行只剩 `.zip`）。
