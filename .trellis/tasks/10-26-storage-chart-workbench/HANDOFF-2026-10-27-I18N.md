## 2. 用户裁定（必须遵守）

1. **设置页只允许 3 个开关**：导出区保留、后端流量提示、教程自动打开。
   Git / 压缩 / 扩展包 / 保留构建配置 / backups / 派生缓存 / 私有配置 / 清理原生资产
   **不得回到设置页**。
2. **图表是唯一选择面**：所有打包选项在图表里；**所有节点正向**——勾选=包含，不勾=不包含；
   **禁止**「清理/删除」反向开关。只有 Git 与扩展有「默认包含」的特殊处理。
3. **扩展组**：`完整扩展包` / `仅清单` 切换；**只有完整扩展时 Git 三档才显现**。
4. **仅清单模式 = 方案 A**：包内放**官方扁平 `index.json`** + `_convert/extensions-manifest.json`；
   无插件时用 ST 原生 `Download Extensions & Assets → Asset URL → Load Asset List`；
   本插件在场时代装。**stock ST 没有「导入 zip 自动装扩展」**。
5. **`file://` 不可用**；无插件最短路径是把 `index.json` 放进 `data/<user>/files/`，
   用 `http://localhost:<端口>/user/files/index.json`（ST 自带路由，已核实）。
6. **设置按钮是齿轮**，不是太阳。
7. **i18n**：zh-CN + en-US 全量；所有 UI 文案从可读 locale 文件取，禁止硬编码。
8. **教程**：高亮环/卡片必须跟随滚动、缩放与宿主 `transform` 容器，不得偏移越界。
9. **先 demo 生效**：`npm run dev` → `http://127.0.0.1:3040/src/ui/ui-demo.html`。
