# 引导入口与全屏引导动画

## Goal

删除向导模式后，用「一个常驻引导按钮 + 全屏引导动画」承担首次使用引导。
引导步骤与真实控件对齐，不引入第二份 UI。

## Requirements

| 编号 | 要求 |
| --- | --- |
| R-01 | 页头常驻一个「引导」按钮 |
| R-02 | 首次安装（本机无引导完成标记）自动进入全屏引导 |
| R-03 | 再次点击引导按钮可重放全屏引导 |
| R-04 | 引导过程可随时退出 |
| R-05 | 引导步骤与真实控件对齐：高亮真实控件，不另画一套假界面 |
| R-06 | 引导内文案同样受父任务 C-07 约束（无括号说明、无分号、无长句） |
| R-07 | 引导完成标记写入本地存储；清除后可再次触发首装路径 |
| R-08 | 全屏引导不影响宿主页面其余部分；退出后焦点回到触发按钮 |

## Acceptance Criteria

- [ ] AC-01（R-01）：页头有引导按钮；截图为证
- [ ] AC-02（R-02）：清除标记后刷新自动进入引导；截图为证
- [ ] AC-03（R-03）：已完成后再次点击可重放；截图为证
- [ ] AC-04（R-04）：任意步骤可退出，退出后回到原界面
- [ ] AC-05（R-05）：每步高亮的是真实控件（同一 DOM 节点），不是副本
- [ ] AC-06（R-06）：引导文案无括号说明、无分号、无长句
- [ ] AC-07（R-08）：退出后焦点回到引导按钮
- [ ] AC-08：五个守卫全绿；`npm test` 零回归
- [ ] AC-09：交付含前后截图对照

## 依赖

需 `10-14-ui-full-rewrite` 的界面结构定稿后才可开工；本任务不改界面结构，只加引导层。
