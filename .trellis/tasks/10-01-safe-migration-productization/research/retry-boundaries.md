# 操作重试边界（S0 取证）

> 取证日期：2026-10-13。回应 codex 会话遗留问题「恢复接口的安全边界」与 `R-07`（部分失败先核对，只重试安全项）。
> 证据为本仓 `file:line`。本片给出**每类操作的可拆分性 / 幂等性 / 重试资格**，作为 `assessRetry`（S1）的输入。

## 1. 四类操作的重试性质

| 操作 | 入口 | 幂等性 | 可拆分性 | 重试资格 |
| --- | --- | --- | --- | --- |
| **源读取** | `fetchHostBackup`（`src/ui/host-bridge.js:724`） | 幂等（只读宿主） | 可断点续传（Range + OPFS 半成品，E-14） | **可自动重试** |
| **格式转换** | `convert`（`src/core/transform.js:312`） | 幂等（纯函数，同输入同输出；不碰宿主） | 逐条目，可 crc 跳过（`appendedNames`，E-14） | **可自动重做** |
| **目标写入** | `restoreToHost`（`src/ui/host-bridge.js:907`） | **非幂等**（`merge` 重复写同一用户目录） | **不可拆分**（整包单请求） | **默认不可自动重试**（见 §2） |
| **原生备份导出** | 宿主原生 UI / `fetchHostBackup` | 幂等（只读） | 可重试 | **可自动重试** |

## 2. 目标写入为什么默认不可自动重试（关键边界）

`postRestoreWithFallback`（`src/ui/host-bridge.js:155-186`）的硬约束（E-6）：

- **404 / 405** ⇒ 该路径无此路由，请求**未达处理器、无副作用** ⇒ 可安全试**下一候选端点**（这是唯一的「自动换端点」场合）。
- **超时 / 5xx / 413 / 网络中断 / 取消** ⇒ 请求**可能已被宿主处理** ⇒ **原样交回，绝不改试另一端点**。
  理由：换端点重试 = 对**同一用户目录重复写入**。

推论：

1. **`restoreToHost` 的失败无法区分「已写一半」与「完全没写」。** 响应丢失 ≠ 没写入。
   ⇒ 任何非 404/405 的失败，`assessRetry` 必须返回**不可自动重试**，转人工核对。
2. **取消是请求级**（`host-bridge.js:49-51`，E-8）：`cancelRestoreInFlight()` 只 abort 本地请求，
   宿主可能仍在处理 ⇒ 取消后**同样不可自动重试**。
3. **在途互斥**（`host-bridge.js:908-911`，E-7）：已有恢复在途时，第二次调用直接抛错 ⇒ 天然防止并发双写。
4. **`mode='overwrite'` 更危险**：整包覆盖 ⇒ 失败后的重试风险高于 `merge`，`D-26` 要求额外明确警告。

## 3. 可自动重试的判定（供 `assessRetry`）

`assessRetry(itemEvidence) -> { allowed, reason }` 的判据（S1 实现，此处定语义）：

- `allowed === true` **当且仅当**同时满足：
  1. 有**充分证据**证明该项**未应用**（例如转换侧 crc 未命中、或源读取失败但从未发起目标写入）；
  2. 该操作**幂等或可拆分**（§1 表中「可自动」的三类）；
  3. 目标、计划、选择、确认**均未变化**（变化即失效，`R-05`）。
- 否则 `allowed === false`，`reason` 指出缺哪一条（如「未知写入状态」「确认已过期」「目标已变」）。

**禁止**：把「UI 上看起来失败了」当作「未应用」。判据必须是**证据**，不是界面态。

## 4. 与断点续传（不变量）的关系

`resume-checkpoint-invariant`（`.trellis/spec/frontend/resume-checkpoint-invariant.md`）锁定：
「断点清单里的完成条目**必须在产物里有对应字节**」。本片不改变该不变量，仅补充：

- 该不变量约束的是**转换**（本地、可拆分）⇒ 续传安全；
- **不**适用于**目标写入**（整包单请求、非幂等）⇒ 写入路径**没有**等价的断点语义，
  中断后的正确动作是「核对」而非「续传」。

## 5. 本片未做的事

- 未对任何宿主实际发起写入（未授权实例写入）。
- `tt` / `pt` 的目标写入路径为「人工交付 / 宿主数据管理面板」，本片不含其重试语义（无自动化端口）。
