# 常见问题解答

## 安装与启动

**装完之后页面打不开或者白屏怎么办？**
通过 Git URL 安装扩展后，通常无需手动运行 `npm install`。如果遇到白屏，可以按 F12 打开浏览器开发者工具的 Console 控制台，查看是否提示文件加载路径错误，或者尝试刷新页面重新加载。

**在 Luker 中安装后找不到扩展？**
Luker 的私有扩展目录结构为 `data/<用户名>/extensions/<扩展名>/`。解压或安装时请直接平铺在该目录下，无需额外新建一层 `third-party` 目录。

**双击 `index.html` 为什么提示无法运行？**
因为现代浏览器的安全策略默认限制通过 `file://` 直接运行模块化代码。在本地作为独立网页使用时，请通过开发服务器打开（如运行 `npm run preview`）；如果你想脱离服务器随时双击打开使用，可以使用 `npm run build:offline` 打包出的专用离线单文件版。

## 数据包转换

**为什么界面底部的「生成导出包」按钮是灰色的？**
需要先在右侧的「数据包列表」中勾选至少一个你想要转换的数据包，生成按钮就会亮起。

**导入了新的数据包，为什么左侧图表显示的还是之前的数据？**
在当前页面导入新包会作为备选包入库。如果你想单独转换全新的数据包，可以在列表中点选该包，或者刷新页面开始全新的转换。

**转换中途暂停后再继续，生成的数据包会缺东西吗？**
请放心，完全不会。暂停时插件会妥善封存已写入的文件切片，点击继续时会自动校验已有文件并平滑接续，最终生成的文件与一次性打包完全一致。

**转换好的数据包存放在哪里？**
全部生成好的文件都会集中展示在页面下方的「导出区」列表中，不会直接弹出强制下载打扰你，你可以随时点击下载或存入本地工作区。

## 从当前酒馆拉取

**点击「从宿主拉取」后没有看到酒馆原生的备份弹窗？**
插件会根据当前酒馆版本自动寻找原生备份操作区域。如果酒馆版本较新且界面改动较大，你可以根据弹窗提示，手动进入酒馆的原生设置页面进行备份。

**拉取备份比较慢或网络中断了怎么办？**
插件支持断点续传下载，网络恢复后重新触发拉取，即可从断点处平稳接续。

## 扩展管理

**普通用户为什么看不到「服务端插件」区域？**
服务端插件需要修改服务器底层依赖，因此专门面向酒馆管理员开放，普通用户界面保持清爽整洁。

**开启自动更新后为什么没有检查？**
自动更新需要扩展能够正确读取到 Git 仓库地址。如果是手动复制进去且没有附带 Git 信息的扩展，可以先通过 URL 重新安装一次以关联官方仓库。

**Git 可视化提交树中云端分支的显示规则是怎样的？**
本地安装的提交历史会完整绘制出分支线条与 Commit 节点，而云端分支会作为标签直观展示最新版本，方便你对比本地进度。

## 隐私与凭据

**配置的 Git 令牌或云端备份账号保存在哪里？**
默认仅保存在当前浏览器的本地存储（LocalStorage）中，绝不上传到任何外部服务器，也不会写入酒馆后端的公共配置文件，保障你的个人隐私。详情可参阅 [隐私与凭据](privacy.md)。

**换了浏览器之后保存的 Git 账号需要重新输入吗？**
在默认的「仅浏览器」模式下，换用新浏览器或清空浏览器缓存后需要重新填写。如果你希望跨设备复用账号，可以在「设置 → 隐私」中选择将凭据存入服务端配置中。

## 平台支持说明

- **局域网互传与 WebDAV**：四款酒馆原生暂未提供相关功能，本插件通过纯前端技术自建实现，方便在各种设备间自由搬运；
- **存储审查面板**：浏览器端提供通用的空间审查能力；Luker 酒馆额外支持读取原生服务端存储数据；
- **扩展加载顺序**：界面中展示酒馆当前的真实加载序号，方便排查插件依赖顺序。
