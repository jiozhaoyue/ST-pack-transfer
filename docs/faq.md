# 常见问题与限制

## 安装

**装完打不开 / 白屏？**
扩展通过 Git URL 安装后不需要 `npm install` 或构建。若白屏，先看宿主控制台是否有
`Failed to fetch dynamically imported module`——那通常意味着仓库里缺文件或路径不对。

**Luker 装了之后所有扩展都没了？**
Luker 的用户私有扩展必须平铺在 `data/<user>/extensions/<name>/`。
嵌套成 `third-party/third-party` 会让该目录下所有子插件失效。

**双击 `index.html` 只看到一句说明？**
浏览器禁止 `file://` 下加载 ES Module。独立形态必须经 HTTP(S) 提供，
或使用 `npm run build:offline` 产出的单文件版。

## 转换

**为什么「生成导出包」按钮不出现？**
必须先在数据包列表勾选至少一个包。

**我喂了第二个包，怎么还是在量第一个？**
同一页面里再喂包不会换源包（只入库）。要处理第二个包请另开一个页面。

**暂停后续传，产物会不会缺条目？**
不会。续传按「半成品里真有它的字节」判定跳过；降级情况会完整重做并在日志里写明。

**产物在哪？**
导出区列表。不自动下载。

## 从宿主拉取

**点「从宿主拉取」后没见到宿主的备份按钮？**
插件只注入备份动作区。若宿主版本改动导致落点变化，插件不会乱注，
此时按提示在宿主原生界面手动进入备份。

**拉取很慢 / 中断？**
支持 Range 续传，重新触发即可从断点继续。

## 扩展

**非管理员为什么看不到「服务端插件」？**
这是设计：一切管理员专属能力对非管理员**完全不渲染**，不留空壳、不发请求。

**自动更新开了但没动静？**
未登记仓库的扩展读不到宿主 `.git` 的 origin 时不允许开启，以免假装会自动更新。

**Git 可视化里云端分支没有落点？**
正常的：云端分支只有名字，插件不伪造提交位置。

## 隐私

**凭据存在哪？**
默认只存本机浏览器，不写 `settings.json`。见 [隐私与凭据](privacy.md)。

**换浏览器后账号没了？**
「仅浏览器」模式下换浏览器或清缓存需要重新填写；要跨设备可用请自行选择「服务端」档。

## 已知限制

- WebDAV 与局域网互传是插件自建能力，四个宿主原生都不提供；
- 宿主存储面板只有 Luker 提供，其它宿主如实显示「未提供」；
- 扩展加载顺序只读——宿主没有写回端点，插件不提供伪编辑；
- 提交 SHA 安装依赖宿主能力，部分宿主不支持，失败会原样回显；
- 纯库模式（给聊天库补缺失聊天 / 从库导出）所用上游接口尚未在真实环境跑通。
