# 隐私与凭据说明

## 核心原则

**你的所有敏感凭据默认仅保存在当前浏览器的本地存储（LocalStorage）中，绝不写入酒馆服务端的公共配置文件。** 你可以在「设置 → 隐私」中自主控制存储方式。

## 涉及的凭据类型

插件绝大多数功能完全不需要登录。只有在需要连接外部代码仓库或云端备份时，才需要填写对应的授权信息：

| 凭据类型 | 适用场景 | 填写内容 | 推荐的最小授权权限 |
| --- | --- | --- | --- |
| **GitHub 令牌** | 下载或更新私有扩展 | `github_pat_…` 或 `ghp_…` | Contents 与 Metadata 只读（经典版选 `repo`） |
| **GitLab 令牌** | 同上 | `glpat-…` | `read_repository`（需读取项目信息加 `read_api`） |
| **Gitee 令牌** | 同上 | 私人令牌 | `projects` |
| **Gitea 令牌** | 自建 Gitea 实例，同上 | 访问令牌 | `read:repository` |
| **S3 云存储密钥** | 备份到云端对象存储 | 节点地址 / 区域 / 存储桶 / 密钥对 | 指定存储桶的读写与管理权限 |
| **WebDAV 账号** | 备份到 WebDAV / NAS | 服务器地址 / 账号 / 密码 | 指定备份文件夹的读写权限 |

填写位置指引：Git 令牌在「扩展管理 → 开发者 → Git 账号」；S3 与 WebDAV 在「迁移与备份 → 公网」。

## 凭据保存位置自主控制

在「设置 → 隐私」页面中，你可以为各项凭据独立选择保存位置：

| 配置项 | 默认设置 | 说明 |
| --- | --- | --- |
| Git 账号与令牌 | **仅保存在浏览器本地** | 仅写入本机 `localStorage`，不会随酒馆后端配置保存 |
| S3 云存储凭据 | **仅保存在浏览器本地** | 保证云端访问密钥仅留在你自己的电脑中 |
| WebDAV 凭据 | **仅保存在浏览器本地** | 安全隔离，避免被其他共用酒馆的用户读取 |

- **仅保存在浏览器本地**：最推荐的隐私安全模式，数据仅存放在你当前的浏览器中；
- **保存到服务端 settings.json**：如果你希望在同一酒馆的其他设备上免去重新输入的繁琐，可以选择存入服务端。后续若切换回「仅浏览器」并保存，服务端的明文记录会被自动清空。

## 本地隐私安全保障

- **纯前端本地处理**：数据包的解压、清洗与重组完全在你的浏览器本地进行，无需经过任何第三方转运服务器；
- **受控的外网请求**：唯一的网络通信是你主动在扩展管理中查询 Git 仓库状态，或者执行你自行配置的云端备份；
- **导出与报告脱敏**：导出日志与问题报告中的 Token 和密钥经统一脱敏层自动掩码；实时日志面板显示原文，输入框用密码框遮挡。

## 私有仓库拉取说明

通过酒馆安装私有仓库时，插件会将你的令牌安全地传递给酒馆后端用于执行克隆操作。安装完成后，你可以根据需要随时撤销或更新该令牌。

## 配置导出与备份

在「设置 → 数据」中，你可以将插件本身的个性化设置、云端配置与界面偏好导出为一份独立的 JSON 文件。在导入时，只有当你明确勾选包含凭据的导出文件时才会恢复账号信息，避免意外冲掉现有的账号。

## 多网络环境自适应

配置账号后，该站点下的公开仓库与私有仓库都能顺畅读取分支、版本标签与更新日志。在特定网络环境下，插件会自动选择顺畅的 API 路径拉取文件，确保查看扩展更新和代码差异时稳定不卡顿。
