# 隐私与凭据

## 一句话

**凭据默认只存本机浏览器，不写入酒馆 `settings.json`。** 存放位置在「设置 → 隐私」里统一控制。

## 四类凭据

插件只有四类外部凭据，其余功能都不需要登录。界面里对应位置都有 `?` 说明。

| 凭据 | 何时需要 | 需要填什么 | 建议的最小权限 |
| --- | --- | --- | --- |
| **GitHub 令牌** | 装 / 更新私有仓扩展 | `github_pat_…`（细粒度）或 `ghp_…`（经典） | Contents + Metadata 只读（经典 `repo`） |
| **GitLab 令牌** | 同上 | `glpat-…` | `read_repository`（另需项目信息加 `read_api`） |
| **Gitee 令牌** | 同上 | 私人令牌 | `projects` |
| **Gitea 令牌** | 自建实例，同上 | 管理访问令牌 | `read:repository` |
| **S3 凭据** | 公网备份到对象存储 | 端点 / 区域 / 水桶 / Access Key / Secret Key | 该桶的读写列举删除 |
| **WebDAV 凭据** | 公网备份到 WebDAV | 服务器地址 / 用户名 / 密码 | 限定一个目录前缀 |

填在哪：Git 令牌在「扩展管理 → 开发者 → Git 账号」；S3 / WebDAV 在「迁移与备份 → 公网」。

## 存放位置（设置 → 隐私）

三项独立开关，逐个选择：

| 项目 | 默认 |
| --- | --- |
| Git 账号与令牌 | **仅浏览器** |
| S3 凭据 | **仅浏览器** |
| WebDAV 凭据 | **仅浏览器** |

- **仅浏览器**：只写本机 `localStorage`，**不写入**酒馆 `settings.json`。
- **服务端 settings.json**：随宿主设置落盘。此时**任何能读 `settings.json` 的人都能看到凭据明文**。
  改回「仅浏览器」并保存后，服务端副本会被清空。

旧账号不会消失：若服务端里已有 Git 账号、而本地从未选择过存放方式，
打开时仍按「服务端」显示，你可以在隐私区主动改成「仅浏览器」。

## 插件会不会把数据发出去

**不会。** 本仓库与插件都没有自己的远端服务：

- 转换全程在浏览器内完成；
- 唯一的外部请求是你在「扩展管理」里主动触发的站点 API 查询（GitHub / GitLab / Gitee / 自建 Gitea）；
- 备份上传只发往你自己配置的 S3 / WebDAV / 对端设备。

## 私有仓库的风险

私有仓库只能由插件**把凭据拼进交给宿主克隆的 URL**（宿主服务端执行 git）。
该 URL 可能被宿主写入该扩展的 `.git/config`（origin 地址）——安装私有仓库前请知悉。
界面、日志、导出报告一律对凭据脱敏（`ghp_…3456`），但宿主自己保存的那份不在插件控制范围内。

## 导出插件数据

「设置 → 数据」可把整个插件的配置导出为一份 JSON。

- 「包含登录凭据」**默认勾选**；OAuth 令牌是它的子项、**默认不勾**。
- 导出只读插件侧的配置，不含数据包与产物。
- 导入时，只有导出明确包含凭据才会覆盖账号，避免「没导凭据」被当成「清空账号」。

## 账号对所有平台链接生效

登录后，同一站点下的公开仓与私有仓都能列分支、读 manifest 与原始文件、查标签与提交，
**不限于私有仓库**。自建主机按你在账号里选的站点类型解释
（GitHub Enterprise → `/api/v3`、自建 GitLab → `/api/v4`、Gitea → `/api/v1`）。

读文件会自动换通道：GitHub 的 `raw.githubusercontent.com` 在部分网络被阻断时改走 API，
私有仓直接走 API；Gitee 走带 `access_token` 的 raw。
