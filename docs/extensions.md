# 扩展管理与打包

入口：工作台左侧面板头的切换按钮（存储图表 / 扩展管理；手机另有数据包）。

## 三个页签

| 页签 | 内容 |
| --- | --- |
| **宿主** | 已装扩展、安装、批量更新 / 卸载、服务端插件（管理员） |
| **开发者** | Git 账号、OAuth、令牌获取指引、开发者开关 |
| **打包** | 按数据包挑选要打包的扩展 |

## 安装扩展

所有安装操作都在面板**固定页脚**的「安装扩展」里，展开时向上挤压列表。

- 支持单个 URL、批量多行、`.txt` / `.json` 导入；
- 每行可写 `url | 分支` 或 `url#分支`；
- 支持分支、标签、commit（commit 宿主可能不支持，失败会原样回显）；
- 私有仓库需要在开发者页配好账号，插件会把凭据交给宿主服务端克隆。

### URL 归一

`owner/repo`、`gh:` / `github:` / `gitee:` / `gitlab:` 短写、无协议地址、仓库页地址
（`/tree/<ref>`、`/blob/<ref>/…`、`/commit/<sha>`、`/releases/tag/<tag>`、GitLab `/-/tree/<ref>`）
都会解析成「仓库根 + ref」。宿主用 URL 最后一段做目录名，直接传页面地址会装错名。

### Web 形态安装

独立 Web 没有宿主。此时安装改为**把仓库文件写进你勾选的数据包**：
先勾一个导入包，按源包布局落到 `extensions/<名>/` 或 `data/default-user/extensions/<名>/`，
随包导出，恢复后由宿主识别。私有仓用已填的 Git 账号逐文件读取，凭据不进日志。

## 已装扩展管理

- 列表头显示数量与排序，扩展行可拖拽排序，自定义顺序会被记住；
- 每行显示远端仓库 URL（点击文本即复制）与私有 / 公开徽标；
- 加载顺序 `#N` 只读展示（宿主没有写回端点，插件不提供伪编辑）；
- 行内动作：更新 / 卸载 / 移至全局或移至用户（作用域互转**仅管理员**）；
- 批量：全选 / 反选 / 取消、批量更新、批量卸载（卸载需二次确认）。

### 逐扩展自动更新

- 开关在开发者页（默认**关**）；开着时宿主页才显示逐行控件。
- 每行可选「关闭 / 仅提醒 / 直接更新」，轮询间隔以秒计。
- 仅提醒模式用宿主原生浮层通知；点击通知即取消本次更新。
- 失败按指数退避；最短 / 最长 / 默认间隔、退避倍数与上限、提醒超时都可手动调。
- 未登记仓库的扩展会现场读取宿主 `.git` 的 origin，读不到就不让开启，不假装会自动更新。

> 所有写操作（手动 / 批量 / 自动更新、卸载、重装、移动、安装）共用一条串行队列，
> 避免并发触发宿主 `.luker-staging-*` 清扫竞态。

## Git 可视化

数据包列面板头有「数据包 / Git」页签。选中扩展后：

- 画出提交泳道图（分叉 / 合并 / 截断悬空线），点提交看 diff；
- 本地分支与 HEAD 以徽标钉在对应提交行（云端分支只有名字，不伪造落点）；
- 给出本地与云端的对齐读数（已同步 / 落后 N 个提交 / 不在窗口内）；
- 可按分支或标签「装到该版本」（提交 SHA 宿主不接受）；
- 远端数据一律按 UTF-8 强制解码，避免中文乱码。

开发者页有两个相关开关（默认关）：**Git 云端读取**（关=零云端请求，只显示本地信息）、
**切换分支按钮**（关=隐藏分支/标签选择与「装到该版本」）。

## 打包

- 按已载入的每个数据包分组，勾选要打包的扩展；**只过滤扩展**，其它类目仍按存储图表勾选。
- 每个包可单独选择 Git 清理（保留历史 / 只留更新所需 / 不含历史）。
- 按目标宿主布局生成产物。

### 仅清单包

不带扩展实体，只产出 `_convert/extensions-manifest.json` 与官方索引。
恢复后在宿主机上按清单在线安装。

### 同名扩展只留一份

同一扩展同时装在「用户级」与「全局 third-party」时，产物只保留用户级——
四个宿主加载时本来也优先用户级。打包页顶部会列出被跳过的全局副本，并给出修复指引。

### 宿主自带插件不打包

`public/scripts/extensions/` 下非 third-party 的内置插件（regex、expressions 等）会被剥离并在提示里点名——
四个宿主各有一套自带插件，跨宿主搬运只会错位。

## 服务端插件（仅管理员）

管理员在宿主页能看到宿主 `plugins/` 的分区：行内更新 / 装依赖 / 删除 + 按 URL 安装。

- **非管理员完全不显示**：不留空壳、不发请求、不显示标题；
- 仓库根有 `package.json` 而没有 `manifest.json` 的会被识别为服务端插件，
  装进扩展目录会被直接拦截，并提示改走宿主管理面板或 `plugins/`。

## 账号与令牌

- 站点：GitHub / GitLab / Gitee / 自建 Gitea，多站点多账号、可设默认、可逐个与全部测试；
- 支持 PAT、账密、`https://user:token@host/…` 形式的凭据提取；
- OAuth：授权码 + PKCE；回调地址必须与本页完全一致（协议 + 主机 + 端口，
  `127.0.0.1` 与 `localhost` 是两个来源）。GitHub 的 token 端点无 CORS，需自建代理或改用令牌；
- 令牌获取指引按站点给出令牌页链接、操作步骤与最小权限。

凭据存在哪里，见 [隐私与凭据](privacy.md)。
