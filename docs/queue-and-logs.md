# 任务队列与更新日志

## 连续任务队列

生成导出包、从宿主拉取、恢复写回、云端备份现在共用同一个长任务队列，按顺序执行；生成任务支持暂停/继续，其余长任务至少提供运行状态与中断。

- **排队**：第一次点「生成导出包」立即开始；执行期间再点，会追加到队列，不会丢请求；
- **显示**：工作台底部常驻「任务队列」，显示运行中、排队中、已暂停、已完成、失败、已中断；
- **暂停 / 继续**：运行中的任务可暂停，暂停后可继续（沿用转换断点，不从头重做）；
- **中断**：放弃当前任务；排队中的任务也可直接移出。生成任务走协作式中止；宿主拉取会中止插件侧请求；恢复写回在批次边界停止；云端备份会中止上传循环（已上传分片保留，可重试去重）；
- **排序**：排队中的任务可上移 / 下移；
- **历史**：最近 20 条结束任务保留在队列里，方便核对；点 × 可移除。

队列里的任务类型包括：生成导出包、从宿主拉取、恢复写回、云端备份（S3 / WebDAV）。只有生成任务显示「暂停 / 继续」；其它任务显示「运行中 + 中断」，不会伪装成可暂停。

## 更新日志

- **自动弹出**：插件版本变化后，第一次打开会弹出本次更新说明；默认开启。
- **不再显示**：弹窗里勾选「不再自动显示更新日志」即可关闭；设置页可重新打开该开关。
- **完整日志**：设置 → 提示 →「查看完整更新日志」，按**最早 → 最新**列出本插件的全部提交；
  构建版含完整 git 历史，宿主直装若没有构建数据则显示发布摘要。

## 日志级别

- 所有级别（含 DEBUG）**始终记录**，不会因为阈值丢弃；
- 默认只显示 **WARN + ERROR**，控制台镜像阈值也是 WARN；
- 设置 → 日志 →「日志级别」可切到「调试（全部）」；日志视图上也有 DEBUG / INFO / WARN / ERROR / SUCCESS 过滤按钮，可随时回看历史。
