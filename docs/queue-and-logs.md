# 任务队列与更新日志

## 连续任务队列

生成导出包、从宿主拉取、恢复写回、云端备份、下载、复制回、导入、云端下载/恢复与局域网传输现在共用同一个任务视图；生成任务支持暂停/继续，其余长任务至少提供运行状态与中断。

- **排队**：第一次点「生成导出包」立即开始；执行期间再点，会追加到队列，不会丢请求；
- **显示**：工作台底部常驻「任务队列」速览；日志视图新增「任务队列」页签，显示全部任务；
- **详情**：点任务行可展开类型、状态、创建/开始/结束时间、耗时、进度条与错误；
- **暂停 / 继续**：运行中的生成任务可暂停，暂停后可继续（沿用转换断点，不从头重做）；
- **中断**：放弃当前任务；排队中的任务也可直接移出。生成任务走协作式中止；宿主拉取会中止插件侧请求；恢复写回在批次边界停止；云端备份会中止上传循环（已上传分片保留，可重试去重）；
- **排序**：排队中的任务可上移 / 下移；
- **历史**：最近 200 条结束任务保留在队列里，方便核对；点 × 可移除。

任务类型包括：生成导出包、从宿主拉取、恢复写回、云端备份、一键自动备份、下载、复制回、导入、云端下载、云端恢复、局域网发送/接收。只有生成任务显示「暂停 / 继续」；其它任务显示「运行中 + 中断」，不会伪装成可暂停。

## 一键自动备份

云端备份卡片新增「一键自动备份」：

1. 自动从宿主拉取数据包到导入区（包卡显示「自动拉取」徽标）；
2. 按当前图表的勾选与扩展完整/清单模式修剪；
3. 按当前目标平台生成导出包（包卡显示「自动生成」徽标）；
4. 上传并校验；成功后按设置删除自动流程包。

删除策略：设置里的「生成导出包后删除导入包」开启时，生成导出后立刻删自动导入包；「备份完成后删除自动流程包」默认开启，上传校验成功后删除剩余的自动导入/导出包。上传或校验失败时一律保留并写日志。

## 更新日志

- **自动弹出**：插件版本变化后，第一次打开会弹出本次更新说明；默认开启。
- **不再显示**：弹窗里勾选「不再自动显示更新日志」即可关闭；设置页可重新打开该开关。
- **完整日志**：设置底部的版本行（固定不滚动）点击即可打开完整提交日志，按**从新到旧**排列；
  构建版含完整 git 历史与发布 tag 映射，发版提交高亮显示 tag 徽标，并可切换「只看发布提交」。
- **文档站**：教程与设置里的「查看文档」固定跳转已部署的 GitHub Pages 文档站，不使用 localhost 或当前路径拼接。

## 日志级别

- 所有级别（含 DEBUG）**始终记录**，不会因为阈值丢弃；
- 默认只显示 **WARN + ERROR**，控制台镜像阈值也是 WARN；
- 设置 → 日志 →「日志级别」可切到「调试（全部）」；日志视图上也有 DEBUG / INFO / WARN / ERROR / SUCCESS 过滤按钮，可随时回看历史。
