# 从当前酒馆直接拉取

直接将当前酒馆里的用户数据导出为一个数据包，而且能一步直接打包成你指定的目标格式。

## 功能入口

在数据包「导入 / 导出」页签的**右侧**，点击「从宿主拉取」即可开启。

## 拉取流程

整个过程清晰直观：

1. **预估提示**：先向你展示本次拉取的预计数据量与本地传输说明。
2. **操作指引**：提示当前酒馆原生备份功能的具体点击位置。
3. **唤起备份**：引导打开酒馆的原生备份界面进行导出。

如果你已经熟悉该流程，可以在提示弹窗中勾选「不再提醒」，后续将直接进入操作。

## 各酒馆的原生操作位置

| 酒馆平台 | 原生备份入口 |
| --- | --- |
| SillyTavern | 原生设置面板备份区的备份按钮 |
| Luker | 账户中心 Backup 区域的开始备份按钮 |
| TauriTavern | 扩展列表中「Data Migration」的导出按钮 |
| PureTavern | 「PureTavern 数据管理」扩展中的导出备份按钮 |

> 提示：插件在界面中仅会在对应的备份操作区添加快捷入口，保持酒馆原生界面的清爽与稳定。

## ST 与 Luker 的导出差异（逐步）

两款宿主在「类目勾选」上行为不同，操作路径也不同。
核心区别：ST 的原生端点不支持 selection 透传，Luker 支持。

### SillyTavern：全量导出 + 插件内过滤

1. 在「从宿主拉取」提示中确认筛选说明：**ST 原生端点忽略类目勾选，必须请求全量包**。
2. 按提示打开 ST 原生设置面板的备份区，点击备份按钮，导出全量用户数据。
3. 下载得到的全量包会进入插件的数据包列表。
4. 在插件里按需勾选要转换的类目，类目筛选在**插件内过滤**生效。
5. 继续转换 / 分卷 / 备份。

> 界面显示的数据量按端点实际行为给出**全量数**，而不是你的勾选数。这是如实反馈，不是估算错误。

### Luker：勾选透传

1. 在「从宿主拉取」提示中确认筛选说明：**Luker 原生端点支持 selection，会直接透传你的勾选**。
2. 在插件里先勾选需要的数据类目。
3. 按提示打开账户中心 Backup 区，点击开始备份。
4. 插件把勾选的类目直接透传给宿主，宿主按勾选导出。
5. 界面显示的是你实际勾选的类目数。

### 其它宿主

TauriTavern 与 PureTavern 的迁移端点按能力探测；不支持时会明确提示，不会假装成功。
PureTavern 部分端点可能返回 501，届时以界面提示为准。

## 拉取完成后

- 拉取完成的数据包会自动出现在右侧的**数据包列表**与左侧的**存储图表**中；
- 你可以继续按需勾选、转换格式、智能分卷，或者将它备份到云端与局域网设备；
- 大体积数据包支持断点续传下载，传输平稳可靠。

## 隐私与安全说明

整个操作完全由你亲自掌控：插件只负责提供快捷入口与操作指引，酒馆的所有备份选项与确认按钮均由你亲自点击确认，酒馆原有的备份习惯与配置完全保持原样。
