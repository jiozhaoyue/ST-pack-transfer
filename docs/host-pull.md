# 从当前酒馆直接拉取

直接将当前酒馆里的用户数据导出为一个数据包，而且能一步直接打包成你指定的目标格式。

## 功能入口

在数据包「导入 / 导出」页签的**右侧**，点击「从宿主拉取」即可开启。

## 拉取流程

整个过程清晰直观：

1. **预估提示**：先向你展示本次拉取的预计数据量与本地传输说明。
2. **操作指引**：提示当前酒馆原生备份功能的具体点击位置。
3. **唤起备份**：引导打开酒馆的原生备份界面进行导出。

如果你已经熟悉该流程，可以在提示弹窗中勾选「不再提醒」，后续将直接进入操作。

## 各酒馆的原生操作位置

| 酒馆平台 | 原生备份入口 |
| --- | --- |
| SillyTavern | 原生设置面板备份区的备份按钮 |
| Luker | 账户中心 Backup 区域的开始备份按钮 |
| TauriTavern | 扩展列表中「Data Migration」的导出按钮 |
| PureTavern | 「PureTavern 数据管理」扩展中的导出备份按钮 |

> 提示：插件在界面中仅会在对应的备份操作区添加快捷入口，保持酒馆原生界面的清爽与稳定。

## 拉取完成后

- 拉取完成的数据包会自动出现在右侧的**数据包列表**与左侧的**存储图表**中；
- 你可以继续按需勾选、转换格式、智能分卷，或者将它备份到云端与局域网设备；
- 大体积数据包支持断点续传下载，传输平稳可靠。

## 隐私与安全说明

整个操作完全由你亲自掌控：插件只负责提供快捷入口与操作指引，酒馆的所有备份选项与确认按钮均由你亲自点击确认，酒馆原有的备份习惯与配置完全保持原样。
