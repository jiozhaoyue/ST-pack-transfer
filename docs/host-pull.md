# 从宿主拉取

把当前酒馆里的数据直接导出成一个数据包，一步直出你选的目标格式。

## 入口

数据包 `导入 / 导出` 页签**右侧**的「从宿主拉取」。

## 流程

顺序固定，不可跳过：

1. **流量提示**：先告诉你这次会拉多少、走的是本机流量。
2. **原生操作指引**：告诉你在宿主原生备份界面该点哪里。
3. **打开面板**：打开宿主的原生备份位置。

提示可以勾选「不再提醒」持久关闭。

## 各宿主的原生落点

| 宿主 | 原生入口 |
| --- | --- |
| SillyTavern | 备份动作区的 `.userBackupButton` |
| Luker | `.backupActionRow`（含 `.backupDownloadButton`），2.9+ 为 `.dw-foot`（含 `[data-act="backup-go"]`） |
| TauriTavern | 扩展列表 →「Data Migration」→ `#data_migration_export_button` |
| PureTavern | 一方扩展「PureTavern 数据管理」→ `#pure-tavern-data-management-entry` → `#ptdm-export` |

> 插件**只注入备份动作区**，不会注入日志弹层或其它面板——宿主有同名的类名，注错位置会干扰宿主。

## 拉取之后

- 拉回的包会出现在**数据包列表**与**存储图表**里；
- 可以继续勾选、转换、分卷，或再写回宿主；
- 大文件支持 Range 续传。

## 隐私说明

插件不会替你点宿主的任何按钮，也不会修改宿主的备份勾选与设置记忆。
它只负责把原生备份入口指给你，剩下的由你自己操作。
