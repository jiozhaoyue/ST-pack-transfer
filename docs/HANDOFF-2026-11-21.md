## 环境注意事项

- **dev server 只监听 IPv6**：`http://localhost:3040/` 可用，`127.0.0.1` 连不上
- **runtime OOM 会连坐**：杀子代理 + dev server，重启后需先核对落盘再重派
- **`scripts/` 被 gitignore 但已跟踪**：普通 `git add` 会静默丢弃，需 `git add -f`
- **`npm run` 冷启动吃满 10 秒**：守卫与测试用 `node <脚本>` 直调
- **`workbench-view.js` 是 9000 行大函数体**：往里写顶层 `export` 会语法崩坏
- **子代理角色写权限**：`verify-*` 只读无 Edit/Write，写任务派 `general-refactor-engineer` / `scout`
- **多子代理同改一文件会行号漂移**：分区派发 + 主代理复核

## 中断恢复方式

本会话曾多次因 runtime OOM 中断。恢复时：
1. 先核对磁盘真实状态（不要信之前的 grep 快照）
2. 用 `SendMessage` 给原 agentId 发「继续」，不要重建同类子代理
3. 若 grep 模式不可靠（如搜测试文件），换更精确的探测方式
