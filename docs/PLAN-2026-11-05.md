## 3. P1 · 图表与布局（Luker 原生观感）

### P1-1 图表自适应网格：边贴边、可拖拽、宽屏最多 4 列

> 2026-11-05 修订：上一版「只竖排、绝不并排」是对「所有图表被压成一条并排」bug 的误判。
> 用户明确要求：图表按网格自适应，宽屏最多 4 个并排，每个图表 DOM 边相互贴着。

- **现象**：桌面版图表 DOM 没有下拉框；所有图表挤成一条、并排堆叠；数值不随选项变化。
- **目标**：
  1. 每个图表 DOM 顶部有**格式下拉框**（条形 / 圆环），切换即时重绘。
  2. **自适应网格**：一行放几个由宽度决定，宽屏最多 4 个；不得把所有图表压成单条。
  3. 每个图表 DOM 的边**相互贴着**（无间隙或统一 1px 分隔线），可拖拽改高度/宽度。
  4. 图表 DOM 无空白区域（高度由内容决定，无固定大留白）。
  5. 所有数值随复选框/下拉变化**实时更新**（无缓存陈旧值）。
- **判据**：
  1. 1280px 视口一行最多 4 个；768px 约 2 个；320px 1 个。
  2. 任意两个图表矩形不重叠；相邻边间距 ≤ 1px。
  3. 拖拽后尺寸落库，刷新后保持。
  4. 改变任一类目勾选，图表数值在下一帧变化。
- **先读文档**：`workbench-single-view.md` §1/§3、`ui-orchestration-rules.md` §1（布局铁律）、`component-guidelines.md`。
- **涉及模块**：图表面板渲染、`#chart-stack`、quota/类目统计。
- **状态**：DONE（代码，2026-11-05）——`#chart-card` 设为容器，`.chart-stack` 改 CSS Grid，`@container` 520/800/1060px 分 2/3/4 列；`.chart-group`/`.vol-grid` 用 `display:contents` 让卡片直连网格，`gap:1px` 贴边；`.vol-card{resize:both}`，右下角拖拽按 `data-volkey` 落 `localStorage`；每卡面板头新增 `[data-chartfmt]`（条形/圆环），切换即时重绘；`[data-volchart]` 用同一份类目数据渲染条形或 SVG 圆环。**列数 / 贴边 / 格式切换已在浏览器实测（见下方补充）；拖拽改尺寸的 `localStorage` 落库尚未单独取证。**
