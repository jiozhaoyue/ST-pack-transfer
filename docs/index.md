# ST-pack-transfer · 数据包转运

轻松在 **SillyTavern / Luker / TauriTavern / PureTavern** 四款酒馆之间迁移、转换、备份与恢复数据包。

纯前端实现：装进酒馆就是一个便捷的功能面板；也可以作为独立网页直接打开使用，完全不需要自己单独部署后端服务。即使在纯浏览器环境下，全部转运功能也能完整运行。

[在线使用（Web 版）](https://jiozhaoyue.github.io/ST-pack-transfer/) ·
[源码仓库](https://github.com/jiozhaoyue/ST-pack-transfer)

## v0.5.2 更新

- **逐扩展双模式**：每个扩展目录行只有「完整 / 清单」两个按钮，想带实体就点完整，想省空间就点清单；组级与批量级只有全完整、全清单、混合三种读数，单图表与多图表逻辑一致。同一个数据包内两种模式可以并存。
- **包内 Git 真实提交**：本地视角直接读取数据包内 `.git` 的 HEAD、分支、refs 与 packfile，列出真实提交；本地 / 云端切换常显，云端读取关闭时明确提示。
- **存储审查纠正**：浏览器侧收敛为四类，中文名不再中英混排；移除与 IndexedDB 混淆的「系统存储配额」分类，配额只在面板头显示。
- **二维码占位**：未生成取件码或二维码库不可用时，只显示写有「未就绪」的矩形占位框，绝不为占位内容生成真实二维码。

## 它解决什么问题

平时使用酒馆时，各家（SillyTavern、Luker、TauriTavern、PureTavern）在保存用户数据（角色卡、聊天记录、世界书、预设、背景图、扩展插件等）时，各自采用了不同的目录规则和文件结构。直接把一家导出的备份包导入另一家，通常会因为目录结构对不上而无法识别。

ST-pack-transfer 专门解决这个痛点：**在任意两款酒馆的数据包之间自由互转**，自动识别并重组目录，尽量帮你完整保留所有的角色、聊天与个性化设置，让你换酒馆、换设备搬家时轻松省心。

## 三种使用方式

| 方式 | 如何打开 | 适合场景 |
| --- | --- | --- |
| 酒馆扩展插件 | 酒馆扩展列表 →「数据包转运」→「打开面板」 | 日常在酒馆内直接备份、恢复与管理扩展 |
| 独立网页版 | 打开在线网址或本地网页 | 纯粹做数据包格式转换与分析，无需启动酒馆 |
| 离线单文件 | 双击运行构建好的单文件 HTML | 无网络、纯离线环境随身携带使用 |
