# ST-pack-transfer · 数据包转运

轻松在 **SillyTavern / Luker / TauriTavern / PureTavern** 四款酒馆之间迁移、转换、备份与恢复数据包。

纯前端实现：装进酒馆就是一个便捷的功能面板；也可以作为独立网页直接打开使用，完全不需要自己单独部署后端服务。即使在纯浏览器环境下，全部转运功能也能完整运行。

[在线使用（Web 版）](https://jiozhaoyue.github.io/ST-pack-transfer/) ·
[源码仓库](https://github.com/jiozhaoyue/ST-pack-transfer)

## 功能亮点

- **完整 / 清单双选**：每个扩展目录「完整 / 清单」两个按钮可以同时点亮；双选 = 实体 + 官方清单条目。本插件、无远端、私有仓库推荐完整，公开远端推荐清单；行内建议徽标更显眼。**网络差或被 GFW 封锁时请选完整**。
- **移动端教程修复**：教程浮层改挂 `document.body` 并使用 `100dvh`，不再被宿主滚动容器带到屏幕外；卡片过高时内部滚动。
- **局域网二维码修复**：二维码编码器改为本地 ESM 直接导入，不再依赖宿主全局 `window.qrcode`，也不会被其它扩展或 CSP 静默掐掉。
- **连续任务队列**：多批生成可排队，运行中可暂停/继续/中断，排队可上移/下移/移出，最近 200 条结束任务保留展示。
- **更新日志与全量日志**：版本变化自动弹更新说明（可关闭）；设置页随时看最早→最新完整提交日志。日志含 DEBUG，默认只显示 WARN 及以上。
- **Luker 引擎自动切换**：在 Luker 里选中数据包后，目标存储引擎自动切到该包声明的源引擎。
- **体积预测更准**：图表预估会扣除 Git 清理将剔除的 `.git` 条目。

## 它解决什么问题

平时使用酒馆时，各家（SillyTavern、Luker、TauriTavern、PureTavern）在保存用户数据（角色卡、聊天记录、世界书、预设、背景图、扩展插件等）时，各自采用了不同的目录规则和文件结构。直接把一家导出的数据包导入另一家，通常会因为目录结构对不上而无法识别。

ST-pack-transfer 专门解决这个痛点：**在任意两款酒馆的数据包之间自由互转**，自动识别并重组目录，尽量帮你完整保留所有的角色、聊天与个性化设置，让你换酒馆、换设备搬家时轻松省心。

## 三种使用方式

| 方式 | 如何打开 | 适合场景 |
| --- | --- | --- |
| 酒馆扩展插件 | 酒馆扩展列表 →「数据包转运」→「打开面板」 | 日常在酒馆内直接备份、恢复与管理扩展 |
| 独立网页版 | 打开在线网址或本地网页 | 纯粹做数据包格式转换与分析，无需启动酒馆 |
| 离线单文件 HTML | 从 [GitHub Release 下载](https://github.com/jiozhaoyue/ST-pack-transfer/releases/latest/download/ST-pack-transfer-offline.html) 后双击 | 无网络、纯离线环境随身携带使用 |
