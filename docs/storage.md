# 存储审查

帮助你清晰了解当前浏览器本地缓存与酒馆服务端的存储空间占用情况。整个审查功能采用纯只读设计，专注于直观呈现空间分布，安全放心。

## 功能入口

在工作台顶部清晰展示了两项存储配额：**浏览器** 与 **宿主**。点击任意一行即可展开审查面板，面板内部也支持随时切换查看来源。

## 可以查看的内容

通过直观的面包屑导航，你可以逐层查看各存储类型的详细占用：

- **网页本地存储**（本地键值存储 / 会话存储）：查看各项设置或缓存键值的大小；
- **浏览器数据库**（本地对象库）：按数据库与数据表查看占用明细；
- **静态资源缓存**（网络缓存）：按缓存分类查看资源大小；
- 配额只在面板头显示「已用 / 总量」，不再重复成一个与 IndexedDB 混淆的分类条目；配额进度条、占比图例与详情列表同屏展示。

## 数据展示说明

- 对于由于浏览器安全策略限制未直接返回确切体积的项，界面会贴心地显示为问号（`?`），明确反映实际读取到的状态；
- 如果当前酒馆原生支持存储审查（如 Luker），插件会自动对接原生数据源展示详细的服务端占用；其它酒馆也会清晰展示当前的支持情况；
- 所有读数均实时反映当前环境的实际占用。

## 空间清理小贴士

存储审查面板主要用于空间状态的盘点与分析。如果你发现存储空间偏大并需要清理，可以按以下方式操作：
- 在右侧「数据包列表」中勾选不再需要的数据包点击删除；
- 或者在「扩展管理」中，将不常用的扩展按需卸载或打包为清单模式（也可完整 + 清单双选），详见 [扩展管理与打包](extensions.md)。
