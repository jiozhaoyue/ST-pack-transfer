# 存储审查

只读地查看浏览器与宿主两处的存储占用。不删除、不改写任何键、库或缓存。

## 入口

工作台顶部有两处配额读数：**浏览器** 与 **宿主**。点哪一行就进入面板并显示哪一侧，
面板内可随时切换数据源。

## 能看到什么

按面包屑逐层下钻：

- `localStorage` / `sessionStorage`：按 key 列出大小；
- `IndexedDB`：按库与表列出；
- `Cache Storage`：按缓存列出；
- 配额行、堆叠条、图例、列表同屏，列表是唯一滚动区。

## 读数的诚实性

- 浏览器不提供的大小如实显示 `?`，**不伪造 0**；
- 宿主数据源只有 Luker 提供（复用其 Storage Inspector），其它宿主如实显示「未提供」；
- 读数与列表同源，不做缓存假值。

## 与数据包的关系

存储审查只读，不会帮你清空间。要清理数据包，去数据包列表删除，
或按包内清理功能只移除扩展（见 [扩展管理与打包](extensions.md)）。
