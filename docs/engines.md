# 存储引擎互转（Luker）

Luker 的用户数据可以放在四种存储引擎里。本功能让你在它们之间互转，不必起临时数据库。

## 能做什么

目标平台选 **Luker** 时，图表多出「存储引擎」下拉：

- **跟随源包**；
- **文件系统**；
- **PostgreSQL**；
- **MySQL**；
- **SQLite**。

选什么就产出什么形态的包：

- 转成**文件系统**后，宿主按原生流程恢复即可，**不再需要起临时数据库**；
- 转成数据库形态则输出对应引擎的转储与元数据，恢复时同样不触发临时库。

## 四种形态任意方向互转

含 PG ⇄ MySQL 这类同构迁移。未来宿主新增数据库时按同一机制扩展。

## 跨宿主同样成立

Luker 的数据库形态转成 ST / TauriTavern / PureTavern 等文件形态时，
会先把数据还原为文件再按目标布局落位（TT/PT 落 `data/default-user/`），不会丢设置与聊天。

## 边界

- 全程本地解析与生成，不上传、不连库；
- 读不出或不认识的格式**如实报错**，不伪造成功。
