# 公开验收指南

本页只描述最终用户可以自己完成的验收步骤。测试前请先备份真实数据；涉及写回的步骤，优先在教程演示模式或一份可丢弃的测试酒馆中完成。

## 一、独立 Web / 单文件 HTML

**目标**：确认解包、四端转换、细粒度勾选、分卷在纯前端环境闭环。

1. 打开在线版，或从 GitHub Release 下载的 offline HTML（https://github.com/jiozhaoyue/ST-pack-transfer/releases/latest/download/ST-pack-transfer-offline.html）后双击运行。
2. 选择一个现成的酒馆备份 ZIP。
3. 检查左侧图表是否正确解析角色卡、聊天、世界书、图片、扩展等类目。
4. 切换目标酒馆，勾选需要的类目，设置分卷大小。
5. 点击「生成导出包」，在导出区下载 ZIP。
6. 解压检查：Luker 目标包含 `manifest.json`；TauriTavern 目标落在 `data/default-user/` 下；PureTavern 目标符合其模块记录结构。

**预期**：所有纯本地转换、分卷、清单生成都可用；「从宿主拉取」「写回宿主」「服务端插件管理」在 Web 模式下明确禁用。

## 二、装进酒馆扩展

**目标**：确认扩展能注入面板，并能读取当前酒馆的数据。

1. 在酒馆扩展管理里从仓库地址安装，刷新页面。
2. 打开「数据包转运」面板。
3. 检查顶部宿主徽标与当前酒馆一致。
4. 尝试「从宿主拉取」，确认能看到当前用户的数据包或分类计数。
5. 切换目标平台，生成一个导出包并下载。

**预期**：面板不遮挡酒馆原有界面；宿主身份、版本与能力提示如实显示；宿主不支持的能力不会假装成功。

## 三、跨宿主往返

**目标**：确认私有配置、扩展与聊天记录在往返后不丢失、不污染目标根目录。

1. 用一份测试酒包从 A 酒馆转到 B 酒馆。
2. 在 B 酒馆导入并检查角色卡、聊天、世界书、预设、扩展。
3. 再从 B 转回 A，检查关键文件是否保留。
4. 检查 B 的顶层目录没有出现 A 的私有文件。

**预期**：不兼容的私有件被封箱到兼容目录；回传时能拆封还原；无法保留的项必须在转换报告中明确列出，而不是静默丢弃。

## 四、备份与分卷

**目标**：确认分卷可独立导入，云端/本地保留策略按用户设置执行。

1. 选择一个接近或超过单卷上限的数据包。
2. 设置分卷大小并生成。
3. 逐个导入分卷，确认顺序与完整性。
4. 配置云端备份保留份数，生成多份快照。
5. 检查最旧的多余快照被删除，最新保留份数完整。

**预期**：每卷都是独立可导入的 ZIP；保留策略严格按用户设置执行，不额外占用配额。

## 五、扩展打包与更新

**目标**：确认完整 / 清单 / 双选三种模式行为符合说明。

1. 在扩展管理中选择一个公开远端扩展，分别用「完整」「清单」及两者同时点亮的「双选」打包。
2. 检查完整包包含扩展实体；清单包只包含清单条目与必要元数据；双选同时包含两者。
3. 把扩展安装到目标酒馆，确认版本与来源显示正确。
4. 制造一次可恢复的本地改动，再次安装或更新，确认能自愈完成。

**预期**：清单模式适合公开远端；完整模式适合离线、私有仓库或无网络环境；双选优先保证实体可用。无法自愈的冲突必须显示明确错误，不得甩锅为网络错误。

## 六、手机与桌面布局

- 桌面按 1440×900 检查：目标平台按钮、图表、数据包列表、日志三态。
- 手机按 390×844 检查：数据包列表可展开/收起，扩展「包内」只能单选，任务队列半展开不遮挡操作。
- 日志三态：收起 → 半展开任务队列 → 全展开日志/队列双页签 → 收起。
