# 计划：UI 响应式修复 + 高价值功能增补 + 界面框架升级评估

记录时间：2026-11-20
状态：计划中 / 阶段性推进

## 一、背景与多模态审图发现

在最新实机多视口渲染截图（桌面 1600×950、移动端 375×860）的多模态深度排查中，确证了以下排版与交互缺陷：
1. **致命视觉遮挡**：移动端抽屉展开后，教程提示气泡居中定位直接盖死空状态下的箱子图标与核心文字。
2. **按钮文案混淆**：右侧栏同时存在两个同名的普通灰色「选择文件」按钮（上方为导入入库，下方为本地独立体检），用户极难分辨。
3. **按钮折行孤立**：移动端扩展管理操作栏中，第 4 个按钮被挤到第 3 行，形成孤单的小图标方块。
4. **桌面大屏下半部留白空泛**：1600×950 下主视图下方有大面积深色留白，卡片未居中或高度自适应。

## 四、第三期：界面框架升级方案评估（详见分析报告）

- 当前技术栈：**原生 Vanilla JavaScript（约 9100 行纯手搓命令式 DOM 操作）**。
- 推荐重构方案：**Vue 3 (Composition API + SFC) + Vite + Scoped CSS**。
- 渐进式实施策略：
  - [x] **P3-1 概念验证（PoC）**：引入 `@vitejs/plugin-vue`，将弹窗模块（如体检报告或问题报告）改用 Vue 3 SFC 编写，验证与宿主环境并存性。（2026-11-21 勾销：已超额完成——Vue 3 真接入落地 `src/ui/vue/mount.js` + `store.js` + `InspectModal.vue`，体检报告弹窗为首个 SFC，含 in-flight 并发守卫与静默降级，`test/vue-build-contract.test.js` 存在）
  - [ ] **P3-2 状态与组件解耦**：将 9100 行 `workbench-view.js` 拆分为响应式 Store 与独立组件（Header、ChartPanel、ZoneList、Modal）。
  - [ ] **P3-3 样式作用域彻底隔离**：利用 `<style scoped>` 彻底消除全局样式污染风险。
