## P1 判据

1. **桌面铺满**：`#app.app-container` 在 `data-view="desktop"` 下为 `100vw × 100vh`、外边距 0、
   圆角 0；页头 / 内容 / 底部进度条都在该容器内；不出现横向/纵向滚动条。
2. **顺序交换**：切换行文本为 `存储图表 / 迁移与备份 / 扩展管理`（手机再加 `数据包`）。
3. **教程跳过**：点「跳过」只关闭浮层，`state.tutorialMode` 保持 true、演示横幅仍在；
   横幅「退出教程」左侧新增「重新打开教程」按钮，点击恢复浮层。
4. **选择锁**：`#app` 默认 `user-select:none`；例外为日志区、输入框 / 文本域 / 下拉、帮助正文。
5. **凭据→开发者**：扩展管理页签文本 `宿主 / 开发者 / 打包`；`data-exttab` 仍为 `cred`（内部键不变）。
6. **Git 账号折叠**：进入开发者页时账号区默认**收起**（`state.extAccountsOpen=false`）。
7. **宿主列表折叠**：已装扩展列表包在可折叠块内，默认展开，标题行显示数量。
8. **安装区方向**：按钮「安装扩展」固定在宿主页**底部**，展开时内容在按钮**上方**出现（向上展开）；
   默认收起，会话内记住。

## P2 判据（下一轮）

- 开发者页：父项「自动更新」+ 子项「检查间隔（小时）」「模式（仅提醒 / 直接更新）」；
  勾父项时子项默认跟随勾选；宿主页逐扩展复选框 + 全选 / 反选 / 取消。
- 更新间隔与模式存 `settings.gitUpdateIntervalHours`（默认 6）/ `settings.gitUpdateMode`（默认 `notify`），
  **禁止硬编码**。
- 管理员识别：宿主返回 `isAdmin` 或等效信号时，列表出现「服务端插件」分区（和前端插件视觉区分、可折叠）；
  非管理员不显示、不伪造。
- 前后端插件误装识别：目标位置与插件类型不符时**拒绝**并给替代方案（改放服务端目录 / 用宿主安装器）。
- `?` 帮助（`HELP.extmgr`）补：私有仓库设置位置、前端/服务端扩展区别、开发者页与 Git 可视化说明。

## P3 判据（再下一轮）

- 入口：开发者模式下，数据包列与 Git 可视化用**同一套切换逻辑**互换（与现有 `net::` 面板同构）。
- 数据源：仅宿主已装扩展的 `*.git`；被清理过要如实显示「历史已丢失」，不伪造。
- 云端：只读该扩展已登记的仓库（`gitInstalls` 同源），只取分支/标签/最近提交，不拉全量历史。
- 只读：分支列表、提交历史、单次提交 diff、工作区状态；**不提供**写操作。
- 占位/示例数据一律**读 JSON 数据文件**（如 `src/data/demo-extensions.json`），禁止在 JS 里硬编码仓库清单。

## 全局纪律

- 占位数据（演示扩展、GitHub `st` 前缀仓库）落 `src/data/*.json`，运行时读取；生成脚本本地专属、不入库。
- 不改宿主真实数据；不向实例目录写文件。
