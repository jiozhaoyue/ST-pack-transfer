# 传输与备份

入口：面板头切换行的「迁移与备份」，整块替换左侧图表面板。

选包只认左侧数据包列表的选中项，面板内不另设文件选择器。

## 局域网互传

- WebRTC 分块 + 二维码信令 + 续传；
- 两台设备在同一网络即可，不经服务端。

## 公网：S3 兼容对象存储

- 需要填：端点 / 区域 / 水桶 / 目录前缀 / Access Key / Secret Key；
- 分片上传、断点续传；
- 填了口令则逐片加密；
- **S3 不走插件的网络代理**：签名绑定域名，转发会失效。

## 公网：WebDAV

- 需要填：服务器地址 / 用户名 / 密码 / 目录前缀；
- 分片上传、断点续传、逐片加密。

### 测试连接

「测试连接」会真实跑一遍：

1. `OPTIONS`；
2. 列目录；
3. 建临时目录；
4. 写小文件；
5. 读回校验；
6. 删除。

逐步显示状态码。测试目录跟随你填的**目录前缀**（与正式上传同一位置），
写的是 `.stpt-selftest/` 下的临时文件并立即删除。
服务器禁用列目录时仍判为「连接可用」，只把该步标成参考项不可用。

## 一键备份

两种模式：

- **全量时间戳快照**：保留最近 N 份；
- **内容寻址增量备份集**：任一版本可独立恢复。

## 凭据说明

公网页签右侧的 `?` 打开「凭据与令牌」，把 S3 / WebDAV 需要哪些字段、建议的最小权限与存放位置一次讲清。

凭据存在哪里、默认存在哪，见 [隐私与凭据](privacy.md)。

## 网络代理

设置 → 网络里的「CORS 代理」只转发插件自己的 Git / WebDAV 请求到一个带 CORS 头的转发地址。
留空即直连。**S3 不走该代理**。

Luker / SillyTavern 原生的 `requestProxy` 与 `enableCorsProxy` 只能改服务端 `config.yaml`，
插件既不修改也不探测它们。
