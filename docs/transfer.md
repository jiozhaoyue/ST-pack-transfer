# 传输与备份

功能入口：在面板顶部的切换栏中点击「迁移与备份」，即可打开专属面板。在左侧数据包列表中勾选你想要传输或备份的数据包即可开始操作。

## 局域网面对面互传

- **扫码即连**：只要手机和电脑连接在同一个 Wi-Fi 或局域网下，扫码即可直接建立点对点直连，开始传输数据包；
- **私密快速**：传输数据直接在两台设备之间对传，不经过任何外部服务器，速度快且完全私密；
- **断点续传支持**：支持大体积数据包分块传输，遇到网络波动时可自动续传。

## 云端备份：S3 兼容对象存储

支持将数据包直接备份到各大云服务商的 S3 兼容对象存储（如阿里云 OSS、腾讯云 COS、Cloudflare R2、MinIO 等）：

- **配置项清晰**：填写节点地址、存储区域、存储桶名称、目录前缀以及访问密钥（Access Key / Secret Key）；
- **可靠传输**：大文件自动切片上传并支持断点续传；
- **安全加密**：如果设置了备份密码，插件会在本地对数据切片进行加密后再上传，云端也无法查看未解密内容；
- **直连保障**：S3 通信采用标准签名校验，默认直接与对象存储服务节点通信。

## 云端与 NAS 备份：WebDAV

支持将数据包备份到支持 WebDAV 协议的网盘或私有 NAS（如群晖、威联通、坚果云、Alist 等）：

- **基本配置**：填写 WebDAV 服务器地址、用户名、密码以及目标保存目录；
- **大文件支持**：同样支持切片上传、断点续传与密码加密保护；
- **一键测试连接**：点击「测试连接」按钮，插件会快速验证目录访问、文件写入与读取权限，并在界面上实时反馈各项测试结果，帮助你快速确认配置是否正确。

## 一键备份模式

插件提供两种灵活的备份策略，满足不同阶段的备份需求：

- **完整快照模式**：每次备份生成一个带有时间戳的独立版本，可按需保留最近的 N 份备份，历史记录一目了然；
- **增量备份模式**：每次仅同步新增或修改的内容，极大节省云端存储空间，而且每个版本依然能随时独立完整恢复。

## 凭据安全说明

在公网配置页面的右上角配有详细的帮助说明，清晰列出各服务所需的最小权限建议。所有 S3 和 WebDAV 凭据默认**仅保存在当前浏览器的本地存储（LocalStorage）中**，不会随酒馆配置落盘，充分保障账户安全。详见 [隐私与凭据](privacy.md)。

## 网络代理设置

如果你在特定网络环境下访问外网 Git 或 WebDAV 服务较慢，可以在「设置 → 网络」中配置专用的 CORS 代理地址；留空时默认采用直连。
