## 第一期：D1 + D2（本轮执行）

### D1 `fmtMB` 对 < 512 字节显示 `0 KB`

- 位置：`src/ui/workbench-view.js:478`
- 现象：`fmtMB(462/1048576)` → `"0 KB"`；0 字节也显示 `"0 KB"`，二者不可区分
- 违反：铁律 5（数据正确性优先、禁假 0）
- 修法：小于 1 KB 时改用字节单位并显式区分 0
  - `0` → `0 B`
  - `1..1023` → `N B`
  - `>= 1024` 维持 KB/MB/GB 现有口径
- 影响面：所有调用 `fmtMB` 的位置（图表、包卡、配额、局域网摘要）
- 验收：单测覆盖 `0 / 1 / 462 / 512 / 1023 / 1024 / 1048576`，断言不再有「非零字节显示 0 KB」

### D2 教程演示态与真实包列表的关系

- 位置：`src/ui/workbench-view.js:328 / 333 / 377`（`if (state.tutorialMode) return;`）
- 待确认：教程态显示 demo 数据是设计行为；真正缺陷应是
  「退出教程后真实包未恢复」或「教程态下导入真实包后无任何提示」
- 验证方法：TT 实机 —— 导入真实包 → 退出教程 → 断言 DOM 出现真实包且体积正确
- 修法（待验证后定）：
  - 若退出未恢复：修 `exitTutorialMode()` 的重载链路
  - 若教程态导入静默：给出明确提示「演示模式不写入真实列表」或直接拒绝并提示
- 验收：退出教程后 `.pkg-card` 的 name/size 与 `listStoredFiles()` 后端真值一致

## 第二期：离线包体检（A+B+C+D+E）

### 检测分层

| 层 | 检测项 | 判定依据 |
| --- | --- | --- |
| A 文件字节 | `size===0` / `size<22` / 头部非 `PK` / 无 EOCD | 零解析，先判空文件 |
| B ZIP 结构 | EOCD 条目数、中央目录偏移越界、ZIP64 标记、disk 字段、本地头与中央目录大小不一致 | 只读中央目录 |
| C 条目画像 | 0 字节条目清单、压缩方法分布、加密条目、非 UTF-8 名、`..` 路径 | 中央目录遍历 |
| D 语义识别 | `detectLayout()`、分卷清单、关键目录特征、空包判定 | 复用 `detect.js` |
| E 可转换性 | `plan-preview` 计划、预计输出条目、全 DROP 判定 | 复用 `plan-preview.js` |

### 硬约束

- **A 层先于解析**：0 字节不送进 ZIP 解析器，否则真实原因被解析异常掩盖
- **只读中央目录**：web/`file://` 下 Worker 降级主线程，不得全量解压
- **零网络**：全部本地计算，不请求任何外部服务
- **结论用人话**：一次输出一句可执行结论（空文件 / 截断 / 非 ZIP / 空包 / 可转换）

### 入口

- 数据包列表：选中包就地体检，结果面板展示
- 外部文件：直接选择本地 zip，不入库

体检结果作为报告附件字段（结构摘要、条目计数、异常清单），与日志导出共用同一脱敏管道。
