# 恢复写回宿主

把数据包写回当前酒馆。入口在数据包 `导出` 区的「上传 / 恢复」。

## 两种恢复模式

| 模式 | 行为 |
| --- | --- |
| **合并** | 覆盖同名文件，**不删**目标里独有的文件 |
| **覆盖** | 先清空对应位置再写入，需要二次确认 |

恢复模式就在 `导入 / 导出` 页签右侧，随页签切换。

## 写入门禁

以下任一情况成立时**零写入**，只给提示：

- 没有可用备份；
- 备份已过期；
- 目标在准备期间发生变化；
- 权限未知。

## 跨引擎净化

从数据库形态的包恢复到文件形态（或反过来）时，会剔除
`_engine_dump.bin` / `_engine_meta.json`，避免 `settings_pkey` 主键冲突。

## 批量恢复

- 逐包容错：一个包失败不影响其它包；
- 结束时给完整报告；
- 可「保留 / 丢弃部分成果」；
- 进度落盘，中断后可继续。

## Luker 大包

Luker 的恢复端点接受 8 MiB 分片，插件自动分片上传，穿过 Cloudflare 100 MB 单请求上限。

## 上传之后

- 恢复成功后，完成条里会给出「刷新页面」；
- 若包内带扩展清单，可选择是否按清单自动安装；
- 详细过程见 [扩展管理与打包](extensions.md)。
